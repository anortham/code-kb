# Launcher review

The lead checked the launcher against the frozen protocol and existing sandbox, snapshot and grading APIs.

- Agent mounts contain only the seeded project, disposable state, named SDK/dependency inputs, native Codex runtime and its required companion. Only the code-kb arm receives intelligence binaries and an index. Private controls, hidden checks, reference patches and other trials remain outside mounts.
- Seed Git history is one local commit with no remote. Canonical tests, instructions, build inputs and Git metadata remain protected. Existing and reserved absent paths remain covered by patch validation.
- Offline dependency setup and the agent reuse state-agent. Preindexing runs without authentication or networking, records its own elapsed time, and verifies unchanged source. Preexisting indexes and interrupted/preindex-failed attempts do not dispatch.
- Host state is recorded before provider execution. Existing and interrupted slots do not silently redispatch. Completed failures and partial timeout patches remain outcomes.
- Independent capture and fresh public/hidden replay determine behavioral results. The launcher leaves final acceptance pending source review even after tests pass.
- Outbound source auditing preserves pinned public source when a broad redactor mistakes ordinary key annotations for secrets. Actual host-secret values are rejected; task/profile payload mutations block execution.
- Structurally redacted JSONL retains parseable events and sanitized actions; malformed original lines have a separate sidecar. Aggregate usage is calculated before redaction, and missing values remain unavailable.
- No financial approval file, spending cap or spending receipt exists in the dispatch path.

Lead found and closed missing preindex/timing, inherited-index and malformed-retained-JSONL issues before any scored task exposure. The 15 focused tests, all 281 Python tests, real preindex probe and native engine visibility probe pass. Existing Linux/Windows runtime evidence remains applicable because engine source and binaries are unchanged.
