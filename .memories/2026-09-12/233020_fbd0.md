## Implemented Tier 2 In-Database FTS5 Conceptual Search (BM25)

Implemented SQLite FTS5 full-text search with BM25 ranking across symbol names, signatures, and doc comments, satisfying Tier 2 of the code-intelligence architecture.

### What
- Added external content virtual table `symbols_fts` referencing `symbols` table with Porter stemmer (`tokenize='porter unicode61'`).
- Added automatic SQLite triggers (`symbols_ai`, `symbols_ad`, `symbols_au`) to maintain zero-overhead index synchronization on insertions, updates, and deletions.
- Implemented query sanitizer with token quoting and prefix expansion (`"token"*`), multi-token AND matching with automatic OR fallback, and contextual bracketed match snippets.
- Added 1:1 `code-kb search <query>` CLI subcommand supporting `--kind`, `--include-tests`, `--limit`, and `--json`.
- Added `search_symbols` MCP tool conforming to Core Invariant 1 (zero workspace parameters exposed).
- Updated `find_symbol` to fall back gracefully to FTS5 when exact symbol name queries return 0 rows.

### Verification
- All 15 workspace tests passing (`cargo test --workspace`).
- Tested live conceptual queries against `code-kb` release binary: `reconcile offline edits` and `format skeleton`.
