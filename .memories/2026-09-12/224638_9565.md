## Implemented Tier 3 Background File Watcher

Added debounced background file watching with git checkout storm circuit breaker for real-time index synchronization during external edits.

### Accomplishments
- Implemented `crates/code-kb-core/src/watcher.rs` using `notify` and `notify-debouncer-mini` (150ms debounce window).
- Added `.gitignore` and hard exclusions (`.git`, `.code-kb`, `target`, `node_modules`, `.idea`, `.vscode`) so build and tool directories are never watched or processed.
- Implemented Git checkout storm circuit breaker: if >50 files change in a 500ms sliding window, cancels micro-updates and falls back to a single bulk scan.
- Integrated watcher lifecycle directly into `McpServer` (`crates/code-kb-cli/src/mcp/server.rs`).
- Added end-to-end integration test `crates/code-kb-core/tests/watcher_test.rs` validating external file edit, addition, and deletion.
- All 10 tests passing across workspace (`cargo test --workspace`).
- Release binary footprint remains tiny at 4.83 MB.
