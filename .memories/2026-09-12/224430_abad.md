## Initial build of code-kb engine and MCP server

Successfully initialized and verified code-kb repository, core SQLite query engine, progressive disclosure serializers, CLI commands, and MCP stdio server.

### Accomplishments
- Initialized Git repository tracking https://github.com/anortham/code-kb.git.
- Scaffolding of Cargo workspace: `crates/code-kb-core` and `crates/code-kb-cli`.
- SQLite connection layer in WAL mode with `PRAGMA query_only = ON;`.
- Fast AST fact queries over `julie-extractors` SQLite schema v7 (symbols, files, references, structural facts, literals, types).
- Byte-precision slicer with UTF-8 char boundary snapping and fallback line-slicer.
- Token-dense progressive disclosure serializers: `file_skeleton`, `codebase_outline`, `get_context_slice`, `format_references`.
- Single-turn atomic AST body edit tool: `replace_symbol_body` with optimistic locking and immediate re-indexing.
- 1:1 CLI commands matching every agent tool (`outline`, `skeleton`, `symbol`, `body`, `slice`, `refs`, `facts`, `edit`, `scan`, `serve`).
- Full MCP stdio server implementation supporting `initialize`, `tools/list`, and `tools/call`.
- 9 unit and integration tests passing (`cargo test --workspace`).
- Release binary footprint: 4.54 MB (well under 15 MB budget).
- Initial commit created and pushed to GitHub main branch.
