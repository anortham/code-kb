## Added structured rolling file logging and `code-kb logs` subcommand

Implemented structured file-based logging for `code-kb` to assist with debugging and issue diagnostics without violating stdio MCP protocol constraints.

- **Workspace log directory:** Non-blocking daily rolling logger writing to `.code-kb/logs/code-kb.log.YYYY-MM-DD`.
- **Stdio hygiene:** In `serve` mode, logs strictly emit to the rolling file appender (never to stdout, preventing JSON-RPC corruption). In CLI mode, errors and info can also emit to stderr if `--verbose` is provided.
- **CLI inspection:** Added `code-kb logs` subcommand with `--lines` option to quickly inspect the log directory and tail recent entries.
- **MCP server telemetry:** Instrument `serve` startup, tool calls, arguments, and execution results.
- **Verified:** Tested with `cargo test --workspace` (all 10 tests passing) and ran `code-kb logs` to verify output.
