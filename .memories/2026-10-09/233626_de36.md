## Why Claude agents skipped code-kb, and the fix

- **WHAT:** `tools/list` now sets `_meta["anthropic/alwaysLoad"]: true` on every tool except `telemetry_summary`. The routing block (both copies), three tool descriptions, and the code-kb skill now give a read order: `file_skeleton` before a Read/cat/sed of a source file, then `get_symbol_body`/`get_symbol_context`; `lookup_symbol`/`find_references` instead of rg on a name.
- **WHY:** Claude Code defers MCP tools behind ToolSearch. Logs (2026-09-09..10-08): Claude subagents with deferred tools and no code-kb in the prompt used code-kb in 75/1,043 transcripts (7%); Codex sends 59% of navigation calls to code-kb.
- **HOW (headless `claude -p` A/B on ~/source/julie, Claude Code 2.1.296):**
  - A current: 0/12 used code-kb. B ToolSearch hint text: 0/12. C 4 tools loaded: 12/12. D all tools loaded: 12/12 small, 10/12 heavy.
  - Heavy tasks: G (D + read-order text) doubled code-kb calls (main 32 vs 17) and cut whole-file reads in main sessions 16 -> 5.
  - E (D, razorback disabled) also doubled code-kb calls: razorback's "optional retrieval aid / smallest sufficient evidence" text suppressed code-kb. F (no bypass mode) did not help.
  - Tool-result tokens per run stayed ~16-20k in every variant; n=6 per cell is too noisy to claim savings.
- **IMPACT:** Every Claude user gets the tools without a ToolSearch step; ~2.5k tokens of schemas per session. Codex verified to still call the tools. Companion razorback branch `feat/code-kb-first` restores code-kb-first wording.
