## Direction research: accuracy and completeness pivot (2026-10-17)

**WHAT:** A 9-agent read-only study compared julie, miller, code-kb, and julie-extractors data, and measured code-kb accuracy, agent session logs, and other tools. Raw evidence and scripts: `~/.code-kb/reports/2026-10-17-direction-research/` (wf.json has all findings; designs.txt has the two toolset proposals).

**WHY:** The 2026-10-10 viability study found no defensible speed or token gain. The owner asked if code-kb should pivot to accuracy and completeness, or become a new tool on julie-extractors.

**Key measured facts:**
- code-kb rows are nearly always true (91% overall, 99% without express), but lists are incomplete: 135 of 593 true call sites on 12 symbols (flask, express, gson). Express: 1 of 313.
- Lead verified: `code-kb refs safe_tempdir` says "108 found"; rg finds 209 sites. The index holds 221 pending rows; 113 with namespace `code_kb_core` or `crate` are dropped with no notice.
- 21 of 49 sampled "(0 found)" answers had real call sites; 7 reproduced live.
- julie-extractors: JS pending member calls only for this/super, imports, typed receivers (`javascript/mod.rs:307-318`, verified). `RelationshipKind::Overrides` exists, but no extractor writes it (verified). `facts` level drops decorators and functions passed as values (setupmethod 0 of 44).
- Sessions (932 organic edit sessions): median 12-19 model calls before the first edit; rg alternation + sed windows in 74-77% of Claude edit prompts; code-kb before only 5.5% of Claude edits. Top compile failure after edit: a name, member, or import that does not exist (Codex 30% of sessions, median 14 calls to the next pass; Claude 10%, median 4). Arity or shape not propagated to an unedited file: Codex 10%, Claude 2%. No user message reported a missed site.
- julie and miller never measured agent outcomes against native agents. Both lost trust through outputs that looked complete but were not (julie codehealth, dead-code). Semantic search, custom edit tools, daemons, and CT got no measured use or lift. Static test selection misses 29-52% of failing test files (miller replay).

**HOW:** Both design lenses (confidence, fewer turns) independently proposed the same core: (1) one reach answer per change, where every row has an evidence label and counts reconcile with the word-boundary text count; (2) a post-edit check from the git diff, pushed by Stop/PostToolUse hooks. Both said pivot code-kb in place, not a new project.

**IMPACT:** The silent-drop defect is the top accuracy fix, and it needs no new extractor data. Direction is not decided; the owner must choose.
