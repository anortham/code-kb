## Phase 2 slice 3: argument counts (arity) in the callers report

**What:** pin julie 3.8.0 (`scripts/julie-pins.json`, `PINNED_JULIE_VERSION`, invariant 7). Each call site carries `arg_count` (`; N args` in text). New `reference_report/arity.rs` excludes a likely or unresolved Python, Java, C#, Go, Rust, Kotlin, or TypeScript call whose count fits no definition of the target (basis ``3 args; `render` takes 1-2``); proven sites never change; JavaScript never. New `reference_report/receiver_types.rs`: receivers typed `any`/`unknown`/`object` (TS), `Any`/`object`/`typing.Any` (Python), `dynamic` (C#), or a type parameter never exclude. `super`/`base` calls are judged by their receiver (Java/Kotlin no longer "resolves to Sub.f"). Rules in `docs/argument-counts.md`; CLAUDE.md summary.

**Why:** plan task 3.3; the count is exclusion evidence that the compiler (or Python runtime) enforces.

**How:** range from parameter rows checked against the signature; receiver counted where a call can pass it; union with same-named methods of every base type (override walk, aliased bases resolved), no range when the walk is cut. Three review rounds fixed C# attribute/`ref this` extensions, override default values, TS `void`, Python class-body aliases, Go grouped parameters.

**Gotcha:** a code-kb binary prefers the julie-extract that matches its own pin, so a slice 2 binary (pin 3.7.2) ignores a 3.8.0 next to it. The fair baseline is `~/.cache/code-kb-accuracy/phase2/s3/base/code-kb` (slice 2 code, pin 3.8.0); gate report `phase2/gate-s2-j38/report.md`.

**Evidence:** 1161 tests; reach gate PASS (excluded C# 317→419, Java 2407→2429, Rust 2627→2631, TS 1852→1964; truth-covering excluded unchanged at 2+2); lost_proven empty; live p50 within +3%, RSS within 1 MB. Final binary `phase2/s3/final/code-kb`.
