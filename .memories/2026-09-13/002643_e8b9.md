## Resolved all 8 Codex/Astra architectural review findings via TDD

Addressed critical safety, freshness, disambiguation, and memory-boundary findings across code-kb-core and code-kb-cli:

- **Finding 2 (Stale Offsets Slicing Crash):** Updated `get_symbol_body_op` to re-query symbol coordinates from SQLite after JIT indexing. Added bounds checks against in-memory slices.
- **Finding 3 (CLI/MCP Extraction Parity):** Unified all query and formatting workflows into `code_kb_core::ops` (`codebase_outline_op`, `file_skeleton_op`, `get_symbol_body_op`, `get_context_slice_op`).
- **Finding 4 (Equal-Size File Edits):** Implemented blake3 content hash comparison in `ensure_fresh_file` and `reconcile_offline_edits` when file byte sizes match.
- **Finding 5 (Symbol Disambiguation):** Added qualified identifier parent joins (`A::new`), exact path matching (`%/path`), and `AmbiguousSymbol` error with candidate listing.

- **Finding 7 (Path Traversal Escapes & URI Normalization):** Added path canonicalization and lexical containment checks (`clean_path`) and RFC 3986 file URI parsing (`parse_file_uri`).
- **Finding 8 (Extractor Discovery & Windows Compatibility):** Used `which::which("julie-extract")` with cross-platform executable naming and forward-slash normalization. Fixed edition prerequisite in README.md.
