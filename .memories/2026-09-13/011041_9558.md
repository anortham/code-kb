## WHAT

Corrected query-path review findings in `crates/code-kb-core/src/ops.rs` and `queries.rs`: outline filters now resolve through `Workspace`, and user input is escaped before SQLite `LIKE` matching.

## WHY

Absolute outline paths were forwarded as repository-relative database prefixes and returned empty output. `%` and `_` in symbol or path filters acted as SQL wildcards, returning unrelated records.

## HOW

Added focused regression tests for absolute root, `.`, nested relative/absolute, external paths, literal symbol wildcards, and literal scoped path underscores. Applied `ESCAPE '\\'` with a shared escaping helper to name, file, scoped-outline, structural-fact, and literal queries.

## IMPACT

Absolute paths advertised by MCP now work for outlines; query inputs remain literal. Core unit suite passes when the locally built `julie-extract` directory is prepended to PATH. The complete-outline implementation remains unbounded by directory width; a per-level cap would need a product decision.
