## Core lifecycle review and repairs

- **WHAT:** Added regressions and repaired `ensure_fresh_file` deletion handling in `crates/code-kb-core/src/sync.rs`; narrowed watcher hard exclusions to whole path components in `crates/code-kb-core/src/watcher.rs`; corrected Linux-inapplicable Windows path test assumptions in `workspace.rs`.
- **WHY:** A deleted source file was treated as fresh, leaving stale SQLite symbols available to `file_skeleton`. Directories such as `targeted/` were falsely excluded because watcher exclusions used string prefixes. Two workspace tests asserted Windows URI/path behavior while running on Linux.
- **HOW:** The freshness guard now queries the indexed record only after `NotFound`, deletes that record through `julie-extract`, and propagates other metadata errors. Watcher exclusion matching splits normalized paths into components. Tests were written first and failed before each production repair.
- **IMPACT:** Focused freshness (6), watcher (2), and workspace unit (4) tests pass with the release `julie-extract` on PATH. Reconciliation remains a separate candidate: in-memory `_seen` stores every repository path and walker errors can trigger false deletions; changing the public report's unbounded vectors requires lead direction.
