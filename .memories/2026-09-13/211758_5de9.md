## Phase 1 Completed: Critical Server Stability

Implemented and verified the 4 foundational stability items from `docs/plans/012-review-findings-and-fix-plan.md`:

- **Item 1: Watcher Storm Loop:**
  - Upgraded from `notify-debouncer-mini` to `notify-debouncer-full = 0.7`.
  - Filtered read/access events (`event.kind.is_access()`) to prevent inotify `IN_OPEN`/`IN_ACCESS` self-triggering feedback loop.
  - Added `.hidden(false)` to watch dotfiles/dotdirs.
  - Added `ensure_fresh_file` size + BLAKE3 hash check before triggering background incremental indexing.
  - Added test `test_watcher_does_not_reindex_on_reads` in `watcher_test.rs`.

- **Item 4: Dynamic Rebind Poisoning & Worktree Switching:**
  - `Workspace::find_workspace_root` now never returns raw file paths and stops at hard-excluded boundaries (`target`, `node_modules`, `.cache`, `.venv`).
  - `bind_workspace` validates candidate workspace roots before committing state, preventing session poisoning on bad paths.
  - MCP tool call handles relative and absolute paths across nested git worktrees (`.worktrees/wt-name`) and switches active workspace/DB seamlessly.
  - Fast-path auto-scan for worktrees: copies parent repository's `.code-kb/artifact.db` and runs `reconcile_offline_edits` (<15ms) instead of full workspace scan.
  - Added regression tests in `mcp_test.rs`: `test_mcp_invalid_path_does_not_poison_session`, `test_mcp_worktree_rebind`, `test_mcp_worktree_auto_copy_fast_path`.

- **Item 2: Hidden Files Startup Reconciliation:**
  - Added `.hidden(false)` to `WalkBuilder` in `sync.rs` so dotfiles/dotdirs are not falsely marked deleted.
  - Added test `test_reconcile_offline_edits_preserves_hidden_files` in `freshness_test.rs`.

- **Item 3: Formatting & CI Workflow:**
  - Formatted workspace with `cargo fmt --all`.
  - Set `CODE_KB_ALLOW_MISSING_JULIE_EXTRACT=1` and `if: ${{ !cancelled() }}` in `ci.yml`.
  - Resolved all Clippy warnings (`cargo clippy --workspace --all-targets -- -D warnings`).
  - Verified sync contract between `AGENTS.md` and `CLAUDE.md`.
  - All 78 tests across the workspace pass cleanly.
