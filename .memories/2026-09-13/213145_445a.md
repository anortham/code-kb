## Phase 2 Completed: Correctness & Data Integrity

Implemented and verified the Phase 2 items from `docs/plans/012-review-findings-and-fix-plan.md`:

- **Item 5 & 6 (File Integrity on Edit):**
  - Read and preserved existing file metadata permissions (e.g. `0755` executable bits) across atomic tempfile replacement and rollback in `crates/code-kb-core/src/edit.rs`.
  - Canonicalized paths via `effective_abs` in `Workspace::resolve_path` in `crates/code-kb-core/src/workspace.rs` so editing through symlinks modifies the target file instead of deleting/replacing the symlink.
  - Added CRLF detection and line ending normalization in `replace_symbol_body` to match the target file format.
  - Added regression tests in `crates/code-kb-core/tests/edit_test.rs`: `test_replace_symbol_body_preserves_file_permissions`, `test_replace_symbol_body_preserves_symlinks`, and `test_replace_symbol_body_normalizes_crlf`.

- **Query Bug Fixes (`queries.rs` & `ops.rs`):**
  - Fixed `get_symbol_by_name_internal` in `queries.rs`: prioritized non-import primary definitions in SQL (`ORDER BY (s.kind != 'import') DESC, (s.kind IN ('function', 'struct', ...)) DESC`) with increased limit, preventing 10+ imports from crowding out actual definitions.
  - Added dedicated `find_related_tests` function in `queries.rs` and integrated into `get_context_slice_op` in `ops.rs`, pushing test filtering into SQLite instead of filtering in-memory against a generic 5-result limit.
  - Added regression tests in `crates/code-kb-core/tests/disambiguation_test.rs`: `test_get_symbol_by_name_not_crowded_out_by_imports` and `test_context_slice_finds_related_tests`.

- **Items 8 & 9 (Packaging & Installability):**
  - Bundled `routing-block.md` inside `crates/code-kb-cli/src/` to eliminate cross-crate boundary path traversal in `include_str!`.
  - Made `build.rs` verification guard skip gracefully when `scripts/julie-pins.json` is absent (for crates.io packaging/installation).
  - Fixed `read_pin` python3 fallback in `scripts/restore-julie-extract.sh` to extract nested JSON keys via regex matching rather than a broken eval string.
  - Updated binary search in `restore-julie-extract.sh` to match exact binary name (`julie-extract` / `julie-extract.exe`) rather than glob `julie-extract*`.

- **Concurrency:**
  - Added exponential backoff retry on `SQLITE_BUSY` in `execute_julie_extract` in `sync.rs`.
