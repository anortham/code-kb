## Pre-2.1.0 fixes: stale tool text and three known defects

- **WHAT:** On branch `fix/pre-2.1.0`:
  - Tool descriptions, `serve --root` help, both skill copies, and the README no longer contain text that became stale after `project_root` was added.
  - A server or CLI started in a folder the tools refuse (not a project, the home folder, a filesystem root) now logs to `<telemetry dir>/logs` (`~/.code-kb/logs`), not `<folder>/.code-kb/logs`. `code-kb logs` reads the same folder. `serve` now logs under its own `--root`.

  - A failed scan of a markerless root whose pinned `--db` file is gone no longer promises a retry.

- **HOW:** `logging::get_log_dir(root, db)` uses the new `server::accepts_root`. `log_files_newest_first` and `latest_log_file` now take a log folder. There is one failing-first test per defect.
