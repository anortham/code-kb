## Verified issue #2 against updated Terraform and fixed C# expression-body leakage

- **WHAT:** Rechecked all four files in public issue #2 against the user's updated Terraform checkout (`61ea339`). All now show their classes and members. `SerApi.cs` exposed a second skeleton defect: expression-bodied methods leaked implementation text and truncated interpolated strings. Updated the C# skeleton signature sanitizer and extended the regression fixture.
- **WHY:** File skeletons must omit implementation bodies. The previous formatter only cut at `{`, and an interpolated `{` inside an expression body caused malformed output.
- **HOW:** Detect the first C# body arrow outside double-quoted strings and parameter lists, while retaining brace handling. Added a regression case with an interpolated expression body and one with a legitimate default string containing `=>`; both failed before the final fix and pass now. Restricted arrow handling to C# to avoid changing type-arrow syntax in other languages.
