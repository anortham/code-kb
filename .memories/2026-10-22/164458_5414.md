## Reach round on feat/test-reach: level walk, JS receiver step, narrow diff seeds

**WHAT**
- `scripts/blast_perf.py`: interleaved old/new timing + peak RSS of `blast-radius` on the corpus clones (30 targets/repo, 3 repeats); flags p50 or p95 >1.5x (+50 ms) or RSS >1.3x (+20 MiB).
- Walk rewritten level by level (`CallerWalk` in queries.rs): one SQL query per level over a JSON frontier (`json_each`), each (symbol, via, reached-again) expanded once. Branches now return a 4th column `origin` (iw.symbol_id) so the open-end check reuses the walk (`called` set); the depth-5 probe extends the same walk instead of walking again.
- JS receiver step in `walk_caller_branches`: identifier `call` whose `metadata_json.receiver` names the object of `obj.name = function` (or `this` inside a function assigned on that object), and no other JS definition assigned on that object name.
- Diff seeds: `changed_symbols` seeds the innermost non-value symbol holding each changed line; whole file only for module-level hunks. `diff_targets` (<=5 callables, non-test) feed `with_report_tests` in ops.rs, which appends callers-report tests and drops report-tied targets from open ends.

**WHY**
- Perf check showed item 2 regressed badly: Newtonsoft.Json p95 3.4 s -> 11.7 s, Gson p50 0.15 -> 0.55 s (second walk for the probe + per-symbol open-end queries).
- Recursive CTE re-expanded each symbol once per depth (UNION dedups (symbol, depth, via)). Python prototype: 2x at bound 3, 3.9x at bound 5, same rows.
- Whole-file diff seeds listed 54-63% of Flask/Cobra suites; with the JS step Express diffs hit the 200-row ceiling.

**Rejected**
- Temp tables for the BFS: `open_read_only` sets `PRAGMA query_only = ON`, which blocks temp-table writes.
- Diff seeds without callers reports: 3 silent misses (cobra 6c3c1163, express 54af593b, ee40a881).

**IMPACT / evidence**
- vs 2.9.0: p95 Gson 2.54 -> 1.98 s, Newtonsoft 3.38 -> 1.99 s; p50 +5..65 ms; peak RSS same; serve retained ~18 MB both.
- Replay (run `diff-reports`, binary 35231489): 0 silent misses both halves; needless 5/47 dev, 9/58 holdout. Express holdout symbol missed 71% -> 57%. Flask/Cobra diff answers now miss what symbol answers miss (cobra dev diff 60% -> 90%) but list ~0% of the suite.
- Two fixes came from holdout cases.
