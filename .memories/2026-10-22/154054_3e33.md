## Test reach items 1 and 2: planted-bug replay and honest blast_radius test lists

**WHAT**
- Item 1: `scripts/bug_replay.py` (`truth`, `recheck`, `run`, `score`) plants one operator flip per commit on cobra (go test), express (mocha), flask (pytest), and records the tests that fail only with the bug. Truth in `evals/bug-replay/*.jsonl` (96 detected bugs: 47 dev, 49 holdout). README in `evals/bug-replay/README.md`, numbers in `docs/bug-replay-baseline.md`.
- Item 2 (`queries.rs` `blast_radius_walk`, `uncalled`, `walk_caller_branches`; `ops.rs` `with_calling_tests`, `follow_deeper`; `formatters.rs` `open_ends_text`):
  - open ends = reached function/method/constructor with no walk caller step (`### Open Ends`, JSON `open_ends`); target exempt when its callers report has proven/likely sites;
  - depth probe: when the walk stops at depth < 5, a walk to depth 5 counts extra tests (`tests_past_depth`, `tests_past_depth_cut`); text only when > 0;
  - fallback walks on from callers-report callers one level deeper; report tests also join a walk-found list.

**WHY**
2.9.0 answers that list tests missed a failing test with no warning in 28/44 dev and 32/46 holdout cases.

**RESULT**
Silent misses 0 on both halves. Needless warnings 7/45 dev (16%), 10/43 holdout (23%, above the 20% mark). Every needless warning is a true statement (bug didn't break those deeper tests). Holdout is not clean: the report-test merge fix came from the last holdout silent miss (Cobra `cmd := rootCmd` in a goroutine).

**Learned**
- Express mocha truth had cascades (one bug's thrown error failed tests in later files: 506 -> 7 real). `recheck` runs each failing file alone.
- Rejected: a generic "callers lie past depth" line (33% needless on cobra diff); replaced by the exact depth-5 probe count.
- Reach gaps left for later: default depth 2 (cobra misses 85-90%), runtime entry points (`Flask.__call__`, `__enter__`), JS member calls stored only as identifiers (express walk reaches no mocha test; diff answers miss 100%).
