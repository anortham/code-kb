## Cut the fixed start cost of code-kb in Claude sessions

**WHAT:** The routing block (both copies) dropped its tool list and the "Saves 80-90%" claim: 2,925 → 971 chars. The server instructions went from 661 to 377 chars. The tool and parameter descriptions are shorter, and the `project_root` description is now "Absolute path of the project or git worktree you work in. Change it when you move to another." Updated: the CLAUDE.md/AGENTS.md invariant 1 text, the test constants, the hook heading asserts, and `evals/mocks/code-kb/_tools.json` (regenerated from the real tools/list).

**WHY:** In a paired benchmark (2026-10-09), code-kb added ~4,900 tokens at session start. That ate most of its per-task saving.

**HOW:** Three arms on 24 read tasks, 2 reps each (KB = old text, LEAN = this text, NOKB). Results:
- The start shrank by ~1,900 tokens.
- code-kb use held: 46/48 runs in both KB and LEAN.
- LEAN vs NOKB: tokens 0.96, seconds 0.92. LEAN vs KB showed no significant difference.
- The cost difference came from prompt-cache warmth, not from code-kb (LEAN's cache was cold).

**IMPACT:** The "exactly one" selector rule stays in the descriptions; `selector_schemas_use_compatible_object_shapes` enforces it.
