## Add Optional file_path to find_references

- **WHAT**: Added `find_references_scoped` with optional `path_filter: Option<&str>` in `code-kb-core`, added `--file` / `-f` to CLI `code-kb refs`, added `file_path` property and alias tolerance (`file`, `path`) to MCP `find_references`, and synchronized documentation across AGENTS.md, CLAUDE.md, README.md, and skill files.
- **WHY**: `find_references` was the only symbol-targeting tool without an optional file path filter to disambiguate symbols sharing identical names across different files.
- **HOW**: Implemented `find_references_scoped` in `queries.rs` and re-exported it in `lib.rs`; delegated `find_references_ext` to `find_references_scoped(..., None)`; updated CLI `RefsArgs` with `#[arg(short = 'f', long)] file: Option<String>` and relativized the path; updated MCP server schema and tool handler to accept and relativize `file_path`; updated sync docs and verified byte-for-byte sync contract tests.
- **IMPACT**: Allows targeted caller/callee lookup on ambiguous symbols without failure; all workspace tests and sync contracts pass cleanly.
