## Implemented Task 1: Core Telemetry Engine Updates

Centralized telemetry database storage from per-workspace `.code-kb/telemetry.db` to global `~/.code-kb/telemetry.db` (overrideable via `CODE_KB_TELEMETRY_DIR`).

- **What:** Added global telemetry database initialization with WAL mode, 365-day pruning, time-window filtering (`Today`, `Last7Days`, `Last30Days`, `ThisMonth`, `LastYear`, `AllTime`), workspace scoping with normalized forward-slash paths, constant-memory O(1) heap SQL aggregation for token savings (`est_tokens_saved`), legacy workspace telemetry migration, and sanitized bug report generation with prefilled GitHub issue URLs.
- **Why:** Prevents telemetry data loss on workspace teardown, enables cross-project token efficiency queries, and provides diagnostic bug reports.
- **How:** Rusqlite SQL queries with `COUNT`, `SUM`, and `ROUND(AVG(duration_ms))` streaming rows without in-memory duration vectors.
- **Impact:** Establishes core database schema and public query API for MCP `telemetry_summary` and CLI commands.
