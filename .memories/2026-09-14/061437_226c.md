## Released code-kb v0.6.1 with Windows Deep-Dive Audit & Hardening

Completed multi-agent adversarial audit on native Windows, resolving path normalization, file locking, and watcher edge cases, followed by a release bump to v0.6.1.

- **Path Normalization & URIs:** Implemented `paths_equal` cross-platform helper, hardened `parse_file_uri` across 2-slash, 3-slash, pipe syntax, and root drive URIs.
- **SQLite Handle Release:** Configured `PRAGMA mmap_size = 0` on Windows connections to prevent Win32 section mapping locks.
- **File Locking:** Added exponential backoff retry for atomic file replacements during transient OS sharing locks.
- **Test Suite:** 159 tests passing cleanly natively on Windows with 0 failures, 0 warnings.
- **Release:** Tagged and pushed `v0.6.1` to GitHub.
