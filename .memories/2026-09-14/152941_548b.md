## Task 3: CLI Commands & Bug Report Subcommand

- **WHAT:** Added time-windowed `--since` filter and `--workspace` scoping flag to `code-kb stats` / `code-kb telemetry`, and implemented `code-kb bug-report` subcommand generating sanitized environment diagnostics and pre-filled GitHub issue URL.
- **WHY:** Complete Task 3 of the Centralized Telemetry and Diagnostics implementation plan.
- **HOW:**
  - Extended `StatsArgs` with `-s, --since` (default: "all"), `-w, --workspace` (scoping to active workspace instead of global aggregation), and `--json`.
  - Added `BugReportArgs` with `-t, --title` and `--json`.
  - Added `Command::BugReport` variant to `Command` enum and wired handler calling `generate_bug_report`.
  - Added comprehensive integration tests in `crates/code-kb-cli/tests/cli_test.rs`.
- **IMPACT:** AI agents and human users can query time-windowed telemetry stats globally or per workspace, and generate one-click GitHub bug reports directly from the CLI.
