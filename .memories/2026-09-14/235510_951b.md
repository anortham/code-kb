## Remediated All 6 Findings from Pre-Merge Review

Applied targeted, evidence-backed fixes for all 6 medium findings identified in the adversarial pre-merge review by Codex:

1. **Pending Reference Target Identity**:
   - In `find_references_scoped`, `find_callee_signatures`, and `impact_walk`, added namespace path matching (`NOT EXISTS ... LIKE ...`) so calls qualified with a foreign module (e.g. `beta::Worker::run`) never falsely match a same-named parent method in another file (`alpha.rs:Worker::run`).
2. **Blast Radius Disambiguation vs Mixed Seeds**:
   - Introduced `compute_blast_radius_scoped` accepting an explicit `symbol_path_filter: Option<&str>`.
   - In `blast_radius_op`, when both `symbol` and `file` are provided, `file` disambiguates `symbol` without adding the entire file as an additive seed in SQLite traversal.
   - `compute_blast_radius` no longer forcibly applies the single file seed onto unrelated symbol seeds in mixed requests.
3. **Structural Fact & Literal Path Boundaries**:
   - In `find_structural_facts_scoped` and `find_literals_scoped`, replaced percent-padded wildcards with exact equality and boundary-checked directory prefix (`replace(path, '\', '/') = :path OR LIKE :dir_prefix ESCAPE '\'`).
   - Prevents `Cargo.toml` from matching `crates/a/Cargo.toml` and `src/api` from matching `src/api_backup`.
4. **Blast Radius Traversal Ceiling Detection**:
   - Added `traversal_ceiling_reached: bool` metadata to `BlastRadiusResult`, populated in `compute_blast_radius_scoped` when the CTE query returns 200 rows.
   - `format_blast_radius` checks this flag directly, ensuring ceiling disclosure functions even when output limit is low (e.g. default 20) or rows are split between tests and non-tests.
5. **Callee Signature Deduplication Before Cap**:
   - Added `SELECT DISTINCT` in `find_callee_signatures` relationships query so deduplication occurs in SQLite before applying `limit`, preventing high-frequency call sites from crowding out distinct callees.
6. **Scoped Structural Fact Category Discovery**:
   - Added `list_structural_fact_categories_scoped` with boundary path filtering and wired it into both CLI (`code-kb facts --path <path>`) and MCP `find_structural_facts` when `category` is omitted.

All unit, integration, and sync contract tests passing cleanly. Clippy and fmt 100% clean.
