## Remediated Grok Code Review Findings (Plan 015 Follow-up)

All 6 findings from the Grok review have been verified and remediated:

1. **Pending Resolution Tightened for Nested Methods (High)**
   - In `find_callee_signatures`, `find_callee_references`, and `compute_blast_radius`, tightened resolution when namespace and receiver are empty: strictly require top-level (`s_to.parent_symbol_id IS NULL`) or same parent (`s_from.parent_symbol_id = s_to.parent_symbol_id`).
   - Sibling methods now only match when parent matches namespace segment, `Self`, or `target_receiver`.
   - Prevented bare calls like `new()` from incorrectly binding to nested methods like `Workspace::new`.

2. **Benchmark Pipe Deadlock Eliminated (High)**
   - Replaced blocking `os.wait4(pid, 0)` before pipe reads with `selectors.DefaultSelector` non-blocking continuous draining of stdout and stderr until EOF.
   - Added `os._exit(127)` on child execvp failure.

3. **LIKE Wildcard Escaping for Namespace Path Matching (Medium)**
   - Replaced raw `s_to.path LIKE '%' || value || '.%'` with escaped `s_to.path LIKE '%/' || replace(replace(replace(value, '\\', '\\\\'), '%', '\\%'), '_', '\\_') || '.%' ESCAPE '\\'`.

4. **Benchmark Rank-1 and Top-5 Precision Scoring (Medium)**
   - Replaced hardcoded `items[0]` checks in `Exact Symbol Lookup`, `Unscoped Symbol Search`, and `Scoped Search` with `next((idx + 1 for idx, it in enumerate(items) if ...), None)`.
   - Evaluates true Top-5 precision (6/6 passing) and Rank-1 precision (5/6 passing).

5. **External Column Probe Completeness (Medium)**
   - Updated `has_pending_namespace_column` to verify `target_namespace_json`, `target_display_name`, and `target_receiver`.

6. **Outline File Cap Pushed Down Ahead of Symbol Loading (Medium)**
   - In `codebase_outline_op`, bounded `files` query (LIMIT 1001) now executes before loading symbols.
   - Pushed `LIMIT 1000` into `load_scoped_outline_symbols` via `bounded_files` CTE.
   - Tailored truncation note for path-filtered scopes (`path matches over 1,000 files`).

All 159 tests passing, `cargo clippy --all-targets -- -D warnings` clean, `cargo fmt` clean, AGENTS.md / CLAUDE.md sync contract intact.
