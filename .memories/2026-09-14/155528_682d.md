## Scoped MCP telemetry errors and grounded token savings

- **WHAT:** Scoped `recent_errors` in MCP `telemetry_summary` to the active workspace (`self.workspace.canonical_root`) even when `workspace_only` is false (keeping cross-workspace aggregates for totals/breakdowns), and grounded token savings calculation in `handle_call_tool` for `file_skeleton`, `get_symbol_body`, and `get_context_slice` using actual file size on disk (`(file_size / 4).saturating_sub(est_tokens)` with fallback to `3x`).
- **WHY:** Prevents error messages containing sensitive file paths and private symbol names from other workspaces from leaking into global telemetry summaries requested by coding agents, and replaces speculative token savings multiplier with actual measured file sizes when available.
- **HOW:** 
  1. In `handle_telemetry_summary`, when `!workspace_only`, perform a second scoped query with `ws_filter` targeting `self.workspace.canonical_root` and overwrite `summary.recent_errors`.
  2. In `handle_call_tool`, resolve the file path argument against the workspace and check `std::fs::metadata`, computing `(file_size / 4).saturating_sub(est_tokens)`.
  3. Added `test_mcp_telemetry_summary_scoped_errors_no_cross_workspace_leak` in `mcp_test.rs` validating error isolation and token savings computation.
- **IMPACT:** Fixes high-severity pre-merge review finding without leaking cross-workspace errors or violating MCP invariants.
