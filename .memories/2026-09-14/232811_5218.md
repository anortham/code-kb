## Task 4 Complete: Path Filter and Category Normalization for find_structural_facts

- **WHAT**: Implemented category normalization/aliases (`config`, `route`/`routes`, `query`/`queries`/`sql`, `model`/`models`) and optional path scoping for `find_structural_facts` and `find_literals`. Added CLI `--path` / `--file` option to `code-kb facts` and `path` property to MCP tool `find_structural_facts`.
- **WHY**: Agents querying `find_structural_facts(category="config")` previously returned 0 matches because raw patterns like `toml.key_value.v1` were not normalized to common conceptual categories. Furthermore, facts could not be scoped to specific directories or files.
- **HOW**:
  - Implemented `find_structural_facts_scoped` and `find_literals_scoped` in `crates/code-kb-core/src/queries.rs`.
  - Added category alias expansion and SQL path filter clauses (`replace(sf.path, '\\', '/') = :path OR replace(sf.path, '\\', '/') LIKE :path_like ESCAPE '\\'`).
  - Delegated `find_structural_facts` and `find_literals` to the scoped functions with `path_filter: None`.
  - Exported scoped functions in `crates/code-kb-core/src/lib.rs`.
  - Added `path` option with alias `file` to `FactsArgs` in `crates/code-kb-cli/src/main.rs`.
  - Added `path` property to MCP schema and handler in `crates/code-kb-cli/src/mcp/server.rs`.
  - Maintained sync contract for `AGENTS.md` / `CLAUDE.md` and root / plugin `SKILL.md`.
- **VERIFICATION**:
  - Added `test_cli_facts_with_config_alias_and_path_filter` in `cli_test.rs`.
  - Added `test_find_structural_facts_and_literals_scoped` in `queries.rs`.
  - All workspace tests passing (`cargo test --workspace`).
  - Clippy clean (`cargo clippy --all-targets -- -D warnings`).
