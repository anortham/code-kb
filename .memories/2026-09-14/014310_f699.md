## Registered code-kb across AGY, Codex, Claude Code, and Grok

Configured local dogfooding for `code-kb` across all 4 major agent harnesses on Windows, pointing to `C:/source/code-kb`:

- **Binary & Extractor**: Built and installed `code-kb` v0.6.0 to `~/.cargo/bin/code-kb.exe` with bundled `julie-extract.exe` side-by-side.
- **AGY**: MCP registered in `~/.gemini/config/mcp_config.json`, skills registered in `~/.gemini/config/skills.json`, and hooks registered in `~/.gemini/config/hooks.json`.
- **Codex**: MCP registered in `~/.codex/config.toml`, skills linked via NTFS directory junction `~/.codex/skills/code-kb`.
- **Claude Code**: Project MCP updated in `.mcp.json`, global MCP configured in `~/.claude.json`, skills linked via NTFS directory junction `~/.claude/skills/code-kb`, and lifecycle hooks (`SessionStart`, `SubagentStart`) in `~/.claude/settings.json`.
- **Grok**: MCP registered in `~/.grok/config.toml`, skills linked via NTFS directory junction `~/.grok/skills/code-kb`, and lifecycle hooks (`SessionStart`, `SubagentStart`) in `~/.grok/hooks/code-kb.json`.
- **Portability**: Updated repository `.mcp.json` to reference `code-kb` on PATH instead of unix-relative target path.
