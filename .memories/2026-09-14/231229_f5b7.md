## Disambiguate Blast Radius Symbol Seeds with Path Hint

- **WHAT**: Updated `compute_blast_radius` to use `seed_paths[0]` as a path hint when resolving symbol seeds if `seed_paths.len() == 1`.
- **WHY**: When a symbol name is overloaded across multiple files (e.g., `handle`), calling `compute_blast_radius` with both a bare symbol name and a specific file path previously failed with `AmbiguousSymbol` because `None` was passed as `path_filter` to `get_symbol_by_name`.
- **HOW**: If `seed_paths.len() == 1`, passed `Some(seed_paths[0])` as `path_filter` to `get_symbol_by_name`.
- **IMPACT**: Allows ambiguous symbol seeds to resolve cleanly to the target file when a seed path is provided. Tested via TDD with new test `blast_radius_disambiguates_symbol_seed_using_seed_path`.
