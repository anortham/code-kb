## Added the `/code-kb:telemetry` skill

**WHAT:** New skill `skills/telemetry/SKILL.md` with an identical copy at `.claude-plugin/skills/telemetry/SKILL.md`. It parses an optional window and the word `workspace`, calls `telemetry_summary`, replies with totals plus only the items that need attention, and ends with the terminal twin `code-kb stats --since <window> [--workspace]`. The preflight script and `test_skills_md_sync_contract` now loop over every skill directory. README names the command.

**WHY:** The user wanted telemetry reachable as a slash command. Only the single `code-kb` skill existed, so users had to describe the intent in words.

**HOW:** RED run: a subagent with no skill found the tool and summarized well but never named the CLI twin and could not scope to the workspace. GREEN run with the skill: correct parameters, workspace scope, compact reply, CLI twin. Dropped the optional `--json` from the twin because the agent had to guess when to use it. No manifest change: both manifests point at the skills directory.

**IMPACT:** Ships with the next release, no release for this alone. Both telemetry runs showed agents calling `find_symbol` and `get_context_slice`, tool names that no longer exist, 109 calls in the last 7 days. Some hook or skill text elsewhere on this machine still names them. Not investigated; out of scope.
