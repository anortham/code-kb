## WHAT

Task 3's SQL preflight found an introduced regression on frozen Hermes scoped get: baseline 18.08 s, ba2f890 candidate 48.88 s. Pending matching dominated at 15.66 versus 44.17 s. The affected regression suite passed, but full-corpus timing caught extra work.

## WHY

The new module-origin checks ran for builders whose return types cannot enter the class traversal. An AND condition did not force SQLite to prune those rows before correlated scope checks. Changing indexes and the nearest-override join did not solve this cost.

## HOW

A read-only captured-query experiment added a lazy CASE requiring valid metadata, non-NULL return type, and an indexed class of that name before evaluating builder_scope. Pending-stage time fell to 17.05 s with the same rows. Applied only that gate in production; the 135 affected core tests pass. Raw SQL, bound values, profiles, and SQLite3.53.2 EXPLAIN plans are under target/receiver-reference-reliability/diagnosis. Standalone probes link existing release libraries; production needs no tracing instrumentation.
