## WHAT

Added a partial `symbols(path, name) WHERE kind = 'import'` index in `ensure_fts_index`, before the ready-FTS return, with column guards and an upgrade regression test. AGENTS.md and CLAUDE.md describe it.

## WHY

The remaining Hermes impact query spent about 5.4 s in ordinary pending-call matching. Scan-status probes found import lookups visiting millions of unrelated symbol rows: alias imports alone visited 8.2 million rows.

## HOW

Use SQLite's existing index mechanism; reference SQL and matching behavior are unchanged. A direct whole-core probe fell from 5.93 to 3.49 s with identical full results; the recursive stage fell from 158.4 million to 76.0 million VM steps. The new index adds 7.8125 MiB on Hermes. The regression failed at 10,016 steps before the fix and now passes below 100. Linux's 547 tests pass; release build is in progress.

## IMPACT

This is the approved second latency pass. Final paired MCP timing/resource measurements and Windows verification still need completion. Diagnostic artifacts are under target/impact-query-latency; reuse the existing paired driver. Broader priority 1 and the token-savings study remain open.
