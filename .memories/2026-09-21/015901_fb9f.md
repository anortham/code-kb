## WHAT

Changed `is_test_path` in `crates/code-kb-core/src/queries.rs` and let `test_path_predicate` follow clause for clause. The rule now runs over the lowercased forward-slash path with a `/` prepended, so `/test/`, `/tests/`, `/__tests__/`, and `/test_` match at the repository root as well as in any segment. The bare endings `test.rs` and `tests.rs` became `/test.rs` and `/tests.rs`, and `test.go` is gone because Go tests are `_test.go`. `tests.cs` stays for the C# convention. `TEST_PATH_CASES` is now 31 `(path, expected)` pairs, and the agreement test asserts the Rust rule and the SQL mirror against the expected boolean, so the rule itself is pinned.

## WHY

Two review findings. First, stored paths are repository-relative, so a root `tests/` tree and any nested `test_*.py` slipped through: on the hermes-agent index the old rule matched 225 of 384,043 symbols under `tests/`. Second, the bare endings hid production files such as `likely_tests.rs`, `latest.rs`, and `attest.rs`. `compute_blast_radius_scoped` shares the function, so its likely-tests improve too.
