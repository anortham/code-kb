## code-kb 2.2.1: dogfood round 3 fixes + outline/search perf

**WHAT**
- blast_radius `possible` rows now require test-client evidence (param/var/call/receiver containing `client`); whole-file row replaces rows of tests in that file.
- Callee rows carry `target` (resolved def or up to 3 candidates) via `describe_callee_targets`.
- Ambiguous name with exactly one non-test candidate resolves to it.
- `inherited_attribute_write` hides `self.x = …` rows whose base class defines x (value or property); applied post-query to returned rows (lookup, search, skeleton).
- Search: owner branch (members of class named by a query word, via trigram) + owner credit 3 only when another word hits the member name.
- Lookup folds non-exact rows into one line when exact rows exist.
- Outline: OutlineScope, streams paths, cap 1000 counts only listed files, namespace/module parents count as top-level, 40 files per subfolder, overload check uses `+` to avoid parent index.
- Mount facts show mount_target/path; nested defs named in hidden bodies; `\` continuations dropped; telemetry "upper bound"; "1 import".

**HOW / learnings**
- Ground-truth harness: traced flask pytest run (sys.monitoring plugin) in scratchpad `flaskgt`, `blast_eval.py` scores blast_radius. possible precision 0.73 -> 0.92.
- SQLite pitfalls: `AND EXISTS(recursive CTE)` is evaluated eagerly -> wrap in CASE; `r.kind='extends'` picks kind index -> use `+r.kind`; `parent_symbol_id IS x` uses parent index scanning all top-level rows -> `+`.
- Search eval (regression, development 1-3) identical to HEAD after reverting constructor kind prior and name-length tie-break (both tested: tie-break +11/-3, constructor prior hurt C# class ranking).

**IMPACT**
- hermes-agent latency: search ~0.36-0.40 s (HEAD 0.36), outline 0.44 s (v2.2.0 5.5 s), lookup/skeleton equal to HEAD.
- 514 Rust tests, 17 plugin tests, fmt, clippy clean.
