## Codex review of 8d5e648..bfba0b8 (plus julie 77cd5314): 4 medium findings, all fixed

Codex verified each finding with an in-memory SQLite copy of the rules. I checked each one against the source.

1. **Relative-import suffix match:**
   - Problem: `../core/util.js` from v4 still matched `v3/core/util.ts` and `util.test.ts`, and `_` acted as a LIKE wildcard.
   - Fix: `relative_import_matches(value, target)` now walks `../` from the caller's folder in a recursive CTE, then compares exact paths for 9 script extensions and `index`.
2. **Inherited-write walk joined pending bases by name:**
   - Problem: an unrelated class with the base's name could hide a real attribute.
   - Fix: a base counts only when no rival class of that name is as close (`path_proximity(rival.path, pe.path)`).
   - Not changed: the same name-only walk still exists in the self/super and fixture walks inside `pending_target_predicate`.
3. **Lookup applied LIMIT before the inherited-write filter.** Fix: `search_symbols_scoped` doubles `fetch` until the limit is full or the rows run out.
4. **`uses_a_client` compared a forward-slash path with a stored backslash path.** Fix: it compares `replace(t.path, '\\', '/')` and the name index finds the row.

**Tests:** 3 integration tests and 1 unit test. The full suite passes 519 tests, clippy passes, and the 17 plugin tests pass.

**Timing:** lookup, search, skeleton, refs, and blast on hermes-agent and zod are the same as the 3f065ea build.
