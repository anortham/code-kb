## code-kb 2.2.1: round-2 dogfood and corpus-review defects fixed

- **Harness defect found:** dogfood round 2 read a stale flask index. A local julie build keeps the pinned version string (3.6.2), so the version guard never rebuilt the index. `scripts/release-dogfood.sh` now runs `code-kb scan --force` in each worktree.
- **Corpus-review fixes (commit f22c60a):**
  - member-access matching;
  - related-test filtering;
  - nested penalty only for rows inside the parent's source;
  - no "in file" count on merged rows;
  - no empty `Signature:` line.
- **Round-2 fixes (this commit):**
  - skeleton: property bodies, `in __init__()`, whole multi-line annotations;
  - outline: plain-files row, overloads once, unsupported files excluded;
  - `Owner.name` in lookup and search text, plus the exact-name count;
  - `super` and nearest-ancestor resolution;
  - calls to a class defined in the caller;
  - constructors get the tests of their class;
  - blast radius: fixture and setup rows replaced by their tests, direct and indirect labels, whole-file rows first, "Showing N of M", `possible` rows with shared words from the target's callees, subclasses, and `@pytest.fixture(name=)`;
  - facts: handler and registered-in labels, a note on the routes Flask adds, literal kinds split out;
  - telemetry: names its baseline;
  - callees in source order.
- **Open for the user:**
  - `test_cli_invoke` needs return-type inference for a local variable (julie has a brief for it);
  - `__main__.py` has no module-level call;
  - julie C# grammar fails on `$@"...""{x}"""` (the fork `anortham/tree-sitter-c-sharp`; 756 radzen files have parse diagnostics; the defect is old);
  - Flask endpoint names are missing from route facts.
- **Verification:** fmt, clippy, 506 Rust tests, and 17 plugin tests pass.
