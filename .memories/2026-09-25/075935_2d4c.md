## Dogfood round 5 (20260925T073705Z): fixes

- **C1, lookup counts:** "at least 17 imports" and a false "limit reached" in `lookup Flask`.
  - Folded exact-name imports no longer count toward the limit. `folds_into_import_line` is shared by the query and the formatter.
  - `search_symbols_scoped` first fetches 4 × limit, cuts before counted row `limit + 1`, and doubles `fetch` only when needed.
- **C5:** `get_symbol_context` now points to `blast_radius` under every related-test list.
- **C6:** `display_kind` shows `attribute` for a property row whose signature starts with `self.`, `this.`, or `cls.`. JSON keeps the raw kind.
- **C7:** `lookup "App."` or `"App::"` uses `owner_members`: the members of classes, modules, and namespaces with that name, in source order. The header says "Found N members of `App`".
- **Perf pitfalls found and fixed before the commit:**
  - `s.is_test = 0` made the planner use the `is_test` index: 2 s on hermes. Fixed with `+s.is_test`.
  - A refill loop that started at `fetch = limit` always ran a second query: +0.12 s. Fixed with `fetch = 4 * limit`.
  - Final timings match the 3f065ea build.
- **Not defects:**
  - X4: CLI tests rank first for "cli".
  - X3: `getattr(Flask, …)` needs variable-reference identifiers, which the julie `facts` level does not have.
- **Known user decisions, again:** the `possible` rows, `test_cli_invoke`, endpoint names.
