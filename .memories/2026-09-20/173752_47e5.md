## Search quality: compared against julie and miller, then fixed code-kb ranking

### WHAT
- New `docs/plans/019-search-quality-comparison.md`: 16 hand-labeled queries on the code-kb checkout, run through `code-kb search`, `julie-server search --semantics off` (8.0.0 Tantivy), and `miller search --arm lexical`.
- Before: code-kb file@1 9/16, sym@1 7/16, file MRR 0.58; julie lexical 10 / 3 / 0.66; miller lexical 11 / 9 / 0.81. code-kb p50 latency 64 ms vs 442 ms julie vs 262 ms miller.
- After the fix: code-kb file@1 15/16, sym@1 12/16, file MRR 0.95, sym MRR 0.79, p50 14 ms. Beats miller on every column.
- Changes in `crates/code-kb-core/src/queries.rs` only:
  1. `sanitize_fts5_query` splits identifiers at case and digit boundaries (`split_identifier`), drops a short English stop-word list, gives no prefix wildcard to tokens under 3 chars, and adds unsplit identifiers plus the whole-query concatenation as OR alternatives. AND form is `("a"* "b"*) OR "ab"*`.
  2. `fts_search_symbols_scoped` runs the OR query when the AND result is empty OR contains only documentation-language rows (`is_documentation_language`, shared `DOCUMENTATION_LANGUAGES` list).
  3. ORDER BY boosts an exact case-insensitive name match before BM25 score.
- 5 new/updated unit tests in queries.rs.

### WHY
Concept queries such as "syntax validation before edit" returned only markdown sections because only docs contained every word; camelCase queries found nothing; exact names ranked below longer names with the same tokens.

### HOW / decisions
- Index-side split-name FTS column dropped: `symbols_fts` is an external-content table over `symbols`, and any SQL function used in its triggers would also have to exist inside julie-extract's process. Query-side alternatives cover both camel->snake and word->camel without an index change.
- Semantic arms of julie and miller could not be measured: julie daemon reported `Embeddings: None`, miller's vector sidecar needs a resident leader. Not pursued.
- The harness script must stay OUT of the checkout: copied into `scripts/` it was indexed and its query list became the top hit for every case. Lives in the session scratchpad; results are pasted into the plan doc.

### IMPACT / verification
- `cargo fmt --check`, `cargo clippy --workspace --all-targets -D warnings`, `cargo test --workspace` (255 tests) all green.
- Cleaned up `.julie/`, `.julieignore`, `.miller/` that the other tools wrote into this checkout; their daemons stopped.
- Still uncommitted on `main` together with the issue-reporting and julie 3.1.3/ARM64 slices. Intended as a third commit: `feat(search): split identifiers, fall through to OR when only docs match, boost exact names`.
