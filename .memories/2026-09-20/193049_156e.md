## Plan 020 task 3 fix round 1: write lock up front, readiness re-check under the lock

Worktree `.worktrees/feat-search-v1.2`, branch `feat/search-v1.2-recall-rerank`, on top of 09a6526.

- **Root cause:** `ensure_fts_index` opened a DEFERRED transaction. Its first statement (`CREATE VIRTUAL TABLE IF NOT EXISTS symbols_fts`, a no-op on an existing index) opened a read snapshot; the next statement needed the write lock. SQLite never runs the busy handler for a read-to-write upgrade, so the second process got `database is locked` at once instead of waiting.
- **Fix (db.rs only):** the cheap readiness check stays outside any transaction; when migration is needed, `rusqlite::Transaction::new_unchecked(conn, TransactionBehavior::Immediate)` takes the write lock first (busy handler applies); readiness is re-checked inside the transaction (`fts_index_is_ready`) and the function returns `Ok(())` without migrating when another process finished while we waited. `ensure_fts_index_path` raises that connection's busy timeout to 60 s (hermes-agent takes 5.8 s on NVMe) and maps migration errors to the new `DbError::FtsMigration` ("FTS index migration failed: ...") instead of `PragmaFailed`.
- **Test:** `migration_waits_for_another_writer_and_does_not_repeat_its_work` holds `BEGIN IMMEDIATE` on connection A for 300 ms in a thread, then commits and migrates; connection B (busy_timeout 5 s) calls `ensure_fts_index` meanwhile. It was red on the old code with `DatabaseBusy` after 0.05 s; green now after 0.40 s. Mutating the inner re-check away makes it fail (`schema_version` 21 vs 15: six extra trigger DDL statements), so the double-check is covered.
- **Verification:** `cargo test -p code-kb-core db::` 14 pass; `cargo test --workspace` 21 suites green (search_corpus_test 7 pass, 5 ignored as planned); clippy clean; `db.rs` fmt-clean. `cargo fmt --check` reports one diff in `queries.rs` from task 4's committed code, not mine.
- **Note:** `queries.rs` had uncommitted changes from another worker in this worktree during the run; left untouched and unstaged.
