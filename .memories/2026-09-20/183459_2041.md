## Codex review of plan 020, all eight findings folded in

### WHAT changed in `docs/plans/020-search-v1.2-recall-and-rerank.md`
- New section: evaluation sets frozen before any code. Plan 019's 26 queries become a regression set; a development set (about 20 queries per repo across code-kb, hermes-agent, julie, miller) is for tuning; a sealed acceptance set (10 per repo) runs once.
- New design 2: migration that can fail safely. One transaction around DDL, filtered population of both FTS tables, marker written last; readiness checks both `_docsize` tables; failures surface to `scan_workspace`, the CLI, and the first tool call instead of `let _ =`. Tests for upgrade, interrupted migration, missing table, extractor-driven scan/update/delete triggers, Windows.
- New design 3: candidate admission per recall source (word branch keeps its pre-LIMIT exact/doc/import rules; name branch has reserved capacity; exact-name always admitted; BM25 only a tie-breaker across branches).
- Design 4 rerank: coverage defined on collapsed-name substring and adjacent split-token joins (digit runs are split by `split_identifier`), stem-insensitive; kind and path priors never beat a strong name match; test intent applies only with include_tests; reference count and language affinity dropped.
- New design 5: `--explain` flag (text breakdown, JSON `explain` object), score semantics, snippets for trigram-only rows, CLI/MCP parity test, docs and schema text updates, in-process rerank timer.
- Design 6 corpus gate uses resolution_test.rs's `scanned_repo` temp-directory pattern, so only fixture files enter the test database.
- Tasks reordered (sets, corpus gate, migration, trigram+admission with measurements, rerank+explain, evaluation, release). Acceptance now per repository on the sealed set plus migration cost and RSS peak.

### WHY
Codex verified against the code that the original plan under-specified migration safety, would have cut trigram-only candidates before reranking, tuned features on the acceptance set, mis-defined coverage for digit runs, and promised explain output that `--verbose` cannot carry.

### IMPACT
Plan is ready to execute in order. Nothing implemented yet. Committed locally; not pushed.
