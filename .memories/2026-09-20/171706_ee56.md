## Adopt julie-extract 3.1.3 with Linux ARM64 and Windows ARM64

### WHAT
- `scripts/julie-pins.json`: version 3.1.3, six assets with sha256 computed from the downloaded archives (julie publishes no sidecar files). `PINNED_JULIE_VERSION` and the AGENTS.md/CLAUDE.md pin text updated.
- `release-binaries.yml` and `ci.yml`: added `ubuntu-24.04-arm` (`aarch64-unknown-linux-gnu`) and `windows-11-arm` (`aarch64-pc-windows-msvc`). The Windows branch checks now use `runner.os == Windows` instead of `matrix.os == windows-latest`.
- `restore-julie-extract.sh`: Linux aarch64 case. `restore-julie-extract.ps1`: picks the triple from `RuntimeInformation::OSArchitecture` (verified on the win-test guest: X64 gives x86_64 triple).
- Launcher `detectPlatform`: `linux:arm64` and `win32:arm64`; test now covers six targets and uses `linux:ia32` as the unsupported case.
- README and RELEASING target lists and the matrix line updated to six targets.

### WHY
The user released julie-extract 3.1.3 with both ARM targets and asked code-kb to adopt it.

### IMPACT
- `.tools/julie-extract` restored to 3.1.3; the local index rebuilt once by the version guard (binary_version 3.1.3, schema 7, facts level). Smoke queries pass.
- 251 cargo tests, Clippy, fmt, 16 plugin tests, preflight steps 1-5 all green. Workflow YAML parses.
- Not verified: the ARM runners themselves. That happens on the first CI run after push.
- Still uncommitted on `main`, together with the issue-reporting work.
