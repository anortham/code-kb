## code-kb v2.5.0 released (GitHub + crates.io), 2026-09-29

- **WHAT:** Released v2.5.0 on commit 5a4a7ba. The GitHub release has 6 archives with sha256 files. code-kb-core and code-kb-cli 2.5.0 are on crates.io.
- **Surprise:** The documented `git push --atomic origin main vX.Y.Z` failed with GH006. Branch protection on `main` (enforce_admins on) needs the 6 required CI checks to pass on the pushed commit itself.
- **Second surprise:** The repo has `push.followTags=true`. Pushing the bump to `release/v2.5.0` also pushed the existing local tag, so the release workflow started before `main` had the bump. That was harmless: the release gate waited for the PR CI on the same SHA.
- **HOW it shipped:** PR #31 ran CI on 5a4a7ba. After green CI, a fast-forward push of 5a4a7ba to main. GitHub marked PR #31 as merged. The release branch was deleted.
- **Verified:** clean plugin launcher install (downloads 2.5.0, lookup works), `cargo binstall`, and `cargo install` all print `code-kb 2.5.0`.
- **IMPACT:** docs/RELEASING.md section 3.4/3.5 and the preflight step 8 text now describe the PR-for-bump flow with `--no-follow-tags`.
