## Release review of main (9084775) since v2.4.0: 5 defects fixed

A review of main since v2.4.0 found two regressions in reference results and two slow queries. The fixes are on branch `fix/release-review-2026-09-29` (worktree `.worktrees/release-review`).

- **TSX/JS/Vue refs dropped (3ec54b1):** the name-only language filter allowed only qml->cpp and razor->csharp to cross. Fix: `JS_FAMILY_LANGUAGES` group in queries.rs. Test: `name_only_type_usages_cross_the_javascript_family_languages`.
- **Supported member_access became a candidate (2577cd9):** the `receiver_builder_calls` UNION counted resolved same-file helper calls as ambiguous builders. Fix: `AND builder_call.resolved_symbol_id IS NULL` in the ambiguity filter. Test: `a_nested_same_file_helper_call_keeps_the_constructor_receiver_supported`.
- **Perf (2577cd9):** `receiver_type_scope` sat inside the receiver/type_facts EXISTS and ran once per joined row. Moved it outside. Newtonsoft `refs Value`: 1.52 s -> 0.66 s, same output.
- **Perf (c54a46d):** `implicit_handler_evidence` scanned all of pending_relationships. Now uses CROSS JOIN from candidate_scope. Flask blast-radius: 331 ms -> 205 ms, same output.
- **AmbiguousSymbol text** now names all four tools that accept `symbol_id`. It gives no `file_path` hint, because the #23 test forbids advice the caller already followed.
- **CLAUDE.md/AGENTS.md** now describe field coverage +6, the 640-byte docstring head, one-word row pruning, the language rule, nearest-type scoping, lambda display, and constructor-only folding.

Both regression tests failed before the fix and pass after it. Full workspace tests, clippy, fmt, and plugin tests pass.
