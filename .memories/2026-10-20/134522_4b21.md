## julie 3.9.0 pinned in code-kb with two C# rules

**What:**
- `scripts/julie-pins.json` and `PINNED_JULIE_VERSION` name 3.9.0; `.tools/julie-extract` is the local build of julie `c81388f3`. Asset checksums stay 3.8.1 until julie is published (RELEASING step 9).
- `EXTRACTION_LEVEL` is `references`; the level tests moved from `full`.
- `edit_check/binding.rs` (`TypedOverloads`): for a C# parameter or signature change, an untouched call whose `arg_types` all equal another overload's parameter types (and not the changed one's) is dropped.
- `csharp_conditional_fallback` in `reference_report.rs`: a bare C# use of a target kept from `#if !X` is `unresolved` when its file opens a namespace under `#if X`. `reference_report_for_edit` takes the removed target's `preprocessorIf` from the base scan (`What::Removed.condition`).
- Bug report: the sibling julie version is parsed with `sync::extractor_version` (it printed `julie-extract 3.9.0`).

**Why julie c81388f3:** `api.render = render` wrote a property that duplicated the function and raised a basis count from 2 to 3 definitions.

**Size mark (1 GiB cache = `JULIE_BULK_CACHE_KIB=-1048576`; a positive value means pages):** hermes-agent 2.45 GB / 1.97 GB / 69 s, aspnetcore 2.14 GB / 1.87 GB / 46 s; code-kb 175 MB vs 276 MB at full.

**Evidence:** fmt, clippy, 1539 tests; new tests `a_csharp_call_whose_argument_types_select_another_overload_is_not_listed`, `a_removed_csharp_fallback_counts_a_use_beside_a_using_under_the_condition_as_unresolved`, `a_csharp_use_of_an_if_not_fallback_beside_a_using_under_the_condition_is_unresolved`.
