## Workspace binding docs, launcher dev overrides, and index self-healing

### WHAT
- README, agent guides, ADR 001, and the showcase site now explain how the server finds a workspace: `--root` for GUI apps (Cursor, Antigravity IDE, Claude Desktop, Visual Studio), CWD for terminal harnesses, handshake roots, then absolute paths in tool calls. Every GUI-app config shows `--root`.
- Launcher: prefers `CODE_KB_BIN`, then `~/.code-kb/bin/code-kb`, then the checkout's `target/release/code-kb`, then the release download.
- Index self-healing: `create_index` in core (worktree copies parent index, else full scan) shared by CLI and server. CLI builds a missing index and reconciles a stale one before answering. Server joins its startup reconciliation thread before the first tool call.

### WHY
- The launcher commit (3f112a9) broke the dev machine: the Claude plugin downloaded an unreleased 1.0.2. Codex clones plugins from GitHub and drops env, so only a file override reaches it.
- Verification in a scratch clone showed the CLI never scanned or reconciled, and a lookup right after session start could answer from a stale index.

### IMPACT
- Dev machine: no code-kb plugins; manual MCP, hooks, and skill symlinks in Claude Code, Codex, AGY, and Grok all run `target/release` via PATH.
- 214 tests green, clippy and fmt clean. Two regression tests added.
