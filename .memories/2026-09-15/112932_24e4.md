## Post-v1.0 Audit Verification and v1.0.1 Release Preparation

- **Audit & Verification:** Ran independent Codex review on `docs/post-v1.0-audit-report.md`. Verified and fixed CRIT-01, MED-01, MED-02, MED-03, MED-05, HIGH-01, HIGH-03, HIGH-04, HIGH-05, LOW-02, and LOW-03.
- **Key Fixes:**
  - `blast_radius`: Fixed seed path matching with underscores and case by using unescaped exact matching with `COLLATE NOCASE` and escaped directory matching with `LIKE ... ESCAPE '\'`.
  - `blast_radius`: Excluded seed symbols from caller blast radius in cyclic call-graphs via `HAVING MIN(iw.depth) > 0`.
  - `blast_radius`: Clamped `max_depth = max_depth.min(5)` at public entrypoint.
  - `lookup_symbol` & CLI `lookup`: Propagated `AmbiguousSymbol` error rather than silently swallowing and falling back to FTS.
  - CLI aliases: Added `--file-path`/`--path` and `--expected-body-hash`/`--body-hash` aliases across CLI subcommands.
- **Version Bump:** Bumped to `1.0.1` across `Cargo.toml`, `crates/code-kb-cli/Cargo.toml`, `.claude-plugin/plugin.json`, `.codex-plugin/plugin.json`, `.claude-plugin/marketplace.json`, `.github/workflows/release-binaries.yml`, and `docs/site/index.html`.
- **Pre-flight Verification:** All 7 release pre-flight gates passed (`scripts/release-preflight.sh`), including sync contracts, clippy, workspace tests, packaging, and the Prax Windows 11 VM guest run (`win-test`).
