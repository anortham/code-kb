## Call resolution ranking (plan 017 finding 4)

**WHAT:** `queries.rs` now has one shared SQL predicate, `pending_target_predicate`, with `call_site_proximity`. It replaces five hand-copied predicates in `find_references`, `get_symbol_context` (callee signatures), and `blast_radius`. Two new rules: a bare call prefers a same-named free function in the same file, then the same directory; a method call through a variable prefers the method on the variable's recorded type (`type_facts`).

**WHY:** Unresolved calls matched every same-named symbol, so `run` in one package merged with `run` in another. Measured on hermes-agent: 11,879 of 39,405 ambiguous bare-call edges narrow to one definition; 2,529 of 175,256 ambiguous receiver calls narrow by type.

**HOW:** New `tests/resolution_test.rs` (4 tests, red first). Three hand-made fixtures (`queries.rs` unit test, `disambiguation_test.rs`) needed an empty `type_facts` table because the predicate now joins it. Docs updated: server.rs tool description, README, both SKILL.md, routing hook, release notes v1.0.2, plan 017 status.

**IMPACT:** All three tools rank the same way. Receiver rule yields little because julie records types only for parameters, annotated bindings, and `self` (not `let b = B;`). Branch `fix/extractor-seam`, not pushed.
