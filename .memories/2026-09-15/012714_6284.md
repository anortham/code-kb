## Pin julie-extract v2.42.3, Verify Worktree Index Workflow, Address Grok Review & Prepare v1.0.0

- **WHAT:** Pinned `julie-extract` to v2.42.3, verified worktree lifecycle and copy-update-query index workflow, addressed all Grok CLI code review feedback, and completed all 7 release pre-flight checks for `v1.0.0`.
- **WHY:** User requested pinning to newly released `julie-extract` v2.42.3, empirical verification of the worktree workflow (create worktree -> copy index -> update & query index), pre-merge review via `/grok-cli`, and preparation for the v1.0.0 release.
- **HOW:**
  1. Updated `scripts/julie-pins.json` with SHA256 checksums across all 4 platforms (aarch64-darwin, x86_64-darwin, x86_64-linux, x86_64-windows) and bumped extractor constant in `sync.rs` and `build.rs`.
  2. Maintained exact byte-for-byte sync contract between `AGENTS.md` and `CLAUDE.md`.
  3. Identified root cause in worktree index copy: `artifact_metadata.root_path` retained parent repo path, causing `julie-extract` root mismatch errors, and on Windows `julie-extract` expects `\\\\?\\` verbatim path formatting.
  4. Implemented `retarget_artifact_root` with verbatim prefix awareness and automatic self-healing in `reconcile_offline_edits`, `ensure_fresh_file`, and MCP server worktree fast-path.
  5. Addressed Grok CLI review findings: converted `retarget_artifact_root` to return `Result<(), DbError>`, ensured table creation and guaranteed write before returning `Ok(())`, added MCP server fallback to full scan on retarget failure, propagated retarget errors, and added comprehensive unit tests for verbatim prefix preservation.
  6. Verified 200+ tests pass cleanly on both Linux and Windows 11 VM (`win-test`).
  7. Bumped version to `v1.0.0` across workspace, CLI dependencies, plugin manifests, release workflows, and documentation.
- **IMPACT:** `code-kb` is fully compatible with `julie-extract` v2.42.3, worktree index copy-update-query workflows are rock-solid cross-platform, all release gates pass cleanly, and the repository is ready for v1.0.0 release.
