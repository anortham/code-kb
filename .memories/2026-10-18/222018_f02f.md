## Slice 1 of accuracy phase 2: the tool surface

### WHAT
- MCP `tools/list` now has 6 tools: `file_skeleton`, `lookup_symbol`, `get_symbol_body`, `get_symbol_context`, `find_references`, `blast_radius`. Removed: `search_symbols`, `codebase_outline`, `find_structural_facts`, `telemetry_summary` (CLI `search`, `outline`, `facts`, `stats` stay). Every tool requires `project_root` and has `alwaysLoad`.
- `lookup_symbols_op` (ops.rs) serves MCP `lookup_symbol` and CLI `lookup`: a plain query with no exact-name row also gets the ranked search rows (deduped, cap counted after dedupe), and a total miss prints the `symbol_not_found_parts` text. CLI `lookup --json` is now one object `{names, ranked, miss?}`; `scripts/reach_gate.py` reads both shapes.
- `sanitize_symbol_name` strips `fn `/`def `/`function ` only when one name follows, and the CLI uses it too (MCP/CLI parity).
- `blast_radius` lists only call-graph tests (callers, fixture users, setup class tests, constructor step); stem/module file rows, shared words, `possible` rows, and handler evidence are gone. Empty text: `No test reaches it through the index. Run the full test suite.`
- Docs, routing blocks, skills, site, evals, scripts updated. Telemetry evals get a scaffold (`evals/fixtures/telemetry_seed.py`) that writes a fixed telemetry DB into the eval's temporary HOME (refuses to overwrite an existing one), so graders check exact numbers again (412 calls, 301 of 412 with a baseline).
