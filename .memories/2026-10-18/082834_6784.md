## JS/TS recall: review rounds 2 to 6, docs, and the review note

Branch `feat/js-ts-recall` (worktree `.worktrees/js-ts-recall`). Phase 1 is on main at 6de37ae. No release until JS/TS and phase 2 land.

### WHAT
- **Round 2 (commit 6452293, G1–G11):** tsconfig `paths`, `require` and `import` conditions, and callback bindings (`reference_report/js_bindings.rs`). The checkpoint for that commit was missed; this one covers it.
- **Round 3 (H1–H10):** package entries use `Loads` (Anyone, Only(kind), Types; `types` last); tsconfig BOM, `extends` lists, unreadable config leaves a workspace package Unknown; a `paths` target on disk but not indexed is Unknown; `.catch(` and `.for(` are method calls; `MAX_RETURN_TYPE` = 200 bounds the typed-arrow scan; `qualified path` is a name-resolved basis.
- **Round 4 (J1–J6):** `require()` skips a `module`-only entry and falls back to `index`; `COMMONJS_EXPORTS_SQL` reads `exports.NAME =` and `module.exports.NAME =`; `${configDir}`; `&&`, `||`, `??` before a group; `external_import` and `NODE_BUILTINS`; a Java field, variable, or parameter never hides a method from a call (`NameRow::is_not_named_by`).
- **Round 5 (K1–K5):** typed arrows after `return`, `yield`, `throw`, `else`, `do`; `{}` nests in the return type; line-end stop; tests for the round 4 rules.
- **Round 6 (lead fix + 1 Sonnet reviewer + lead fix):** `returns_to_arrow` nests `<>` and `[]`, skips quotes (with escapes) and `//` and `/* */` comments, stops on `,` outside brackets; `type_continues(last, after)` carries a line end when no code came before it or a `|`/`&` joins the lines; `ARROW_KEYWORDS` = return, throw, yield, else, do; `code_before` drops line comments above a group that starts its line.
- **Docs:** CLAUDE.md and AGENTS.md (identical) describe rivals, the resolver rules, Node builtins, and the Java field rule. Review note: `docs/reviews/2026-10-18-js-ts-recall.md`.

### WHY
- Recall on the reach gate: overall 0.803 → 0.911 (go 1.000, javascript 0.995, typescript 0.651), proven precision 1.000 everywhere, no lost proven truth site in 7 projects.
- Each review round found shapes that gave a wrong `proven`; precision comes first, recall second.

### HOW (decisions)
- Kept `yield` in `ARROW_KEYWORDS`: `yield (f): T => …` is valid; the cost is a false binding in `c ? yield (x) : …` (recall only).
- Kept the "nothing before the line end" rule: it reads a return type on the next line; the cost is a false binding for a ternary that ends a line with `:` (recall only, a known gap).
- Rejected a naive `//` strip on the group's own line: on 173k local files it made 373 false bindings (URLs in minified code, groups inside comments).
