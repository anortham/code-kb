## WHAT

Repaired `scripts/benchmark_quality.py` and added `scripts/test_benchmark_quality.py`.

## WHY

Default benchmark runs wrote no JSON report unless `--large-corpus` was enabled. The reconciliation probe accepted lookup fallback text that echoed its query, so historical reconciliation timings could be false positives.

## HOW

Moved report writing outside the large-corpus branch, require a matching function declaration and probe path, validate MCP response ids/errors/`isError`, add per-tool MCP discarded warm-ups, and record CLI warm samples and p95. Reports now include binary SHA-256, externally supplied commit metadata, and workload shape.

## IMPACT

New results are comparable by measured p95 and raw samples. Historical default-run JSON output and fallback-based reconciliation success must be treated as untrusted.
