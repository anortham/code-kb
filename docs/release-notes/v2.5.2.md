# code-kb v2.5.2

This patch release updates the plugin skills. The code-kb binary and its tools give the same answers as in v2.5.1, and it bundles the same julie-extract 3.7.2. The SQLite artifact schema stays at version 7, so no index is rebuilt.

## Skills

- `code-kb`: the description says what the skill does and when to use it. The body is about a third of its old length: one tool table with the CLI twin of each tool, and only the rules that change a call. Telemetry and bug reports moved to their own skills.
- `telemetry` is renamed to `code-kb-telemetry`. In the plugin the command is `/code-kb:code-kb-telemetry`; `/code-kb-telemetry` also works.
- `code-kb-telemetry` counts every code-kb version. `telemetry_summary` counts only the running version by default, so a window that spans a release reported too few calls. The terminal check it prints is now `code-kb stats --since <window> --version all`.
- `code-kb-telemetry` and `report-issue` show an argument hint in the slash-command menu.
- The duplicate skill copy under `.claude-plugin/skills/` is removed. Claude Code reads the skills from `skills/`.

## Tests

- A test checks that each skill's name matches its folder, that the name and description follow the Agent Skills limits, and that each body stays under 500 lines.
- `evals/` holds three `claude plugin eval` cases per skill, with a mocked code-kb server. `scripts/plugin-eval.sh` runs them.

## Known gaps

- `blast_radius` `possible` tests for flask `handle_user_exception` still include tests that match only by shared words and never reach it, and miss `test_trusted_hosts_config`.
- `blast_radius` on flask `src/flask/cli.py` lists whole-file `constructor-only callers` rows that push out the focused CLI tests, and leaves out the example tests that build `Flask` through `create_app`.
- `search_symbols "import Flask"` returns no import rows; `lookup_symbol` with `kind="import"` lists them.
- `find_references` callers names the first three import locations and points to `lookup_symbol` for the rest.
- `file_skeleton` joins a function's decorators on one line and cuts long decorator arguments.

## Release checks

- `scripts/release-corpus-check.py` against v2.5.1 on 15 real projects plus the julie fixtures: PASS, with no changed tool output, symbols, or call edges.
- One dogfood round in Claude Code and Codex on a flask worktree used every tool and checked each answer against the source. It found no wrong answers. The gaps above come from that round.
- With the plugin, the nine `claude plugin eval` cases pass. A live Claude Code session loaded `code-kb-telemetry` and `report-issue` when it should, and `report-issue` waited for approval before it submitted anything.
- Linux, macOS, Windows, and plugin launcher test suites pass.

## Distribution

The GitHub release provides archives for six targets. Each archive bundles `code-kb` and the pinned `julie-extract` 3.7.2 with a `.sha256` checksum.
