# code-kb v2.11.0

This release bundles julie-extract 3.10.0 and uses its new facts. The callers
report now ties an overloaded call to the overloads that its arguments allow,
resolves the import sources of eleven more languages, and names anonymous
classes. `blast_radius` finds more of the code and tests that read a target.
The file watcher moves to notify 9, so a lost Windows watch is no longer
silent. It keeps SQLite schema 8.

## Overloads

- `reference_report/overloads.rs` reads the argument facts that julie writes
  on a call (count, types, Kotlin and Scala names, Swift labels). It decides
  which overloads a call can bind in Java, Kotlin, Scala, C#, C++, Swift, and
  VB.NET.
- A site whose call binds only other overloads is `excluded`, with a basis
  such as ``arguments `(String)` bind only `run(String)` ``. The `blast_radius`
  walk drops such a step, and `check_edit` uses the same rule.
- An exclusion must be certain. A type name is read through the scope rules
  of its language: imports, packages, namespaces, `using` and `Imports`
  levels, type parameters, and nested types. A name that the index cannot
  tie to one type is unknown, and the call keeps every overload it fits.
- A value that can be null where julie writes no `?` (C# `int?`, Swift
  `Int!`, a Kotlin nullable) keeps the overload that takes the null value. A
  literal, a `new` object, or a name declared with a plain type does not.
- A call on the line of its caller's definition now gets the overload check.

## Callers report

- julie 3.10.0 writes the `source` and `form` of imports in C, C++, CSS,
  Bash, PowerShell, R, Ruby, F#, Dart, PHP, and GDScript.
  `reference_report/loaded_files.rs` resolves each path as its language
  reads it. A loaded file can prove a bare call, an included C or C++
  header proves its declaration, and a Dart prefix or a GDScript `preload`
  reaches only the files it names.
- julie names an anonymous class `anonymous_class_L<line>`. code-kb renames
  it to the type it creates and the symbol that creates it, such as
  `<anonymous Task in make>`. The walk steps from a member to the creator.
- The class chain follows `implements` edges, so a call reaches a Java
  `default` method or a Kotlin interface method with a body.
- A site counts another definition only in a language that its call can
  reach. A Java site no longer counts TypeScript or C# definitions.
- An R `<<-` or `->>` to a defined global is a write, not a definition.
- A CSS custom function counts as a definition that every loaded stylesheet
  can call.

## C and C++ includes

- A C or C++ site now reaches only the definitions in the files that its
  includes reach, and the source file with the stem of an included header. A
  copy of a class in a header that the site's file never includes (such as the
  ABI test copy in nlohmann/json) is no longer the definition a call resolves
  to, so it no longer adds false tests or false open ends to `blast_radius`.
- A `.c` or `.cpp` file that another file includes (a template source, a
  unity build) sees what the file that includes it sees.
- The rule decides nothing when julie did not record an include (`#import`,
  `#include_next`, a macro), when an include matches more than 8 indexed
  files, or when the walk passes its size or time limit.
- A call qualified by a namespace that defines the name no longer steps to a
  global function of the same name in the `blast_radius` walk.

## blast_radius and check_edit

- A method read as a value (`return [app.handle_error]`) is an impacted
  symbol, and the walk goes on from it.
- A file target joins the callers of its symbols' reports and lists the
  tests that read a decorated command or a module-level object.
- The page size no longer changes which rows a call finds. Before, a small
  `limit` dropped rows that the callers reports joined.
- The broader test scope lists the command of each runner with the number of
  paths it covers, and names the paths that no runner covers.
- New test commands for Zig, QML, C (Unity, Check, CMocka), gdUnit4, Kotest,
  MUnit, and test-unit, and for JUnit tests through Gradle and Maven (Java,
  Kotlin, Scala), RSpec, and Rake `TestTask` (Minitest).
- A Gradle test in a subproject runs its own project task from the settings
  folder (`./gradlew :moshi-kotlin-tests:test --tests '…'`). Before, the
  command was `cd sub && ../gradlew test --tests '…'`, which also filtered the
  child projects and failed. A project that the settings file includes under a
  condition or a loop gets no command. A `buildSrc` folder is its own build,
  and an `includeFlat` project runs from the folder of its settings file.
- A Maven test in a module of a multi-module build runs from the reactor
  root: `mvn package -pl extras -am -Dtest=pkg.Class#name
  -Dsurefire.failIfNoSpecifiedTests=false`. Before, `cd extras && mvn test`
  could not find a sibling `SNAPSHOT` module and failed. `package` builds the
  jars that a module test on the module path needs. A module that only a
  profile lists, a path from a property, and a nested aggregator get no
  command. A single-module project keeps `mvn test`.
- An sbt test in a subproject runs from the build root by its project id
  (`sbt 'core/testOnly *Suite'`). Before, `cd core && sbt` started a separate
  build without the root settings.
- The open-ends list ends with `N more; pass offset 3 to list them.`

## Search

- A query word that names the row's module earns credit. The module name
  follows the language: a Go package clause, a Rust crate name, a SwiftPM
  target, a Zig `build.zig` module, a Dart library, and more.

## Index and watcher

- A file storm that reaches the queue over several debounce windows now
  starts one bulk scan, not one extractor process per file.
- On Windows the rebuild remedy gives a command for PowerShell and one for
  Git Bash, with quoted paths.
- The file watcher uses notify 9.0.0-rc.7. notify 8 discarded a Windows
  `ReadDirectoryChangesW` start or rearm failure and a buffer overflow with no
  signal, so the index could go stale. Now a failure is an error that the next
  tool call reports, and an overflow starts a reconcile and a new root watch.
  Each second the watcher also checks that its Windows root watch still
  exists.
- macOS now watches the project root recursively, like Windows. notify 9
  refuses an FSEvents stream with more paths than a twelfth of the open-file
  limit, so with notify 9 per-folder watches fail in a project with more than
  about 21 folders. This change is not yet tested on a Mac.
- Reconciles after lost events start at least 1 s apart, so a build that
  overflows the Windows buffer again and again does not keep a core busy.
- The watcher asks notify for create, remove, and modify events only. A file
  read is no event.
- Retained memory of `serve` is about 3 MB higher with notify 9.

## Reach gate

- The gate truth now gives each Java, C#, and C++ overload its own truth.
  Before, it joined the overloads of one name, so a call that binds another
  overload counted as a true site of the target. The revision removed only
  such lines. The gate passes in every language.

## Upgrade

- julie-extract 3.10.0 is bundled. The version guard rebuilds each index once
  on the first call.
- julie 3.10.0 reads versioned SwiftPM manifests (`Package@swift-*.swift`),
  records a Ruby `autoload` as an import, and keeps escaped quotes in test
  names.
- Some callers-report sites change label: overloaded calls in seven
  languages, imports in eleven languages, and anonymous class members.

## Known gaps

The dogfood round on Flask found these gaps. Each answer is true but
incomplete.

- `blast_radius` on `src/flask/cli.py` does not list `test_cli_name`, which
  reads an attribute that `Flask.__init__` sets.
- `blast_radius` and `get_symbol_context` on `Flask.handle_user_exception`
  find no test, because the framework calls it at run time. The answer names
  the open end.
- `blast_radius` labels a method that reads the target as a value
  `direct caller (find_references)`.
- `find_references` labels a `flask.Flask` annotation `likely` where a
  `flask.Flask(...)` call through the same import is `proven`, and it repeats
  a construction site in three sections.
- `check_edit` does not list a write to a removed field, and it keeps 50 test
  commands, one per file.
- `blast_radius` shows three open ends per page.
- `get_symbol_body` calls a property getter and setter `overloads`.
- `file_skeleton` on a folder counts unsupported files without their names.

The release corpus check found these gaps:

- A call to a Ruby method that `define_method` makes in a `Class.new` block is
  `unresolved` (sinatra). 2.10.1 linked it in the same file.
- A call on the line of a Kotlin expression-body `override fun` lost its
  `; N args` (moshi).
- C++ overload binding counts arguments only, so a call with an integer
  literal keeps an overload that takes a class reference (nlohmann
  `parse_error::create`).
- A test that the callers report adds to `blast_radius` shows without its
  `Class::` prefix.
