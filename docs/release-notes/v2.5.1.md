# code-kb v2.5.1

This patch release bundles julie-extract 3.7.2. The code-kb tools give the same answers as in v2.5.0. The SQLite artifact schema stays at version 7. The first start rebuilds an index that julie-extract 3.7.1 wrote.

## julie-extract 3.7.2

- Windows paths in artifact metadata and reports no longer keep the `\\?\` prefix.
- Incremental `scan`, `update`, and `delete` accept another spelling of the same source root and repair the stored spelling.
- A write that another process prepared before a rebind of the index to a new root fails with `artifact_changed` instead of overwriting the new root.
- A forced scan for a different root replaces the facts and metadata in one transaction, so a failed write keeps the original index.
- Extraction rules and parser dependencies are the same as in 3.7.1.

## Tests

- The test for a worktree whose parent index is locked now calls again while the index builds, and prints the server logs when it fails (#33).

## Known gaps

- `blast_radius` `possible` tests for flask `handle_user_exception` still include tests that match only by shared words and never reach it, and miss the tutorial `abort` tests.
- `blast_radius` on flask `src/flask/cli.py` lists 17 whole-file `constructor-only callers` rows that push out the focused CLI tests at the default limit. A test that is the only constructor-only test in its file shows as its own row, not as a file row.
- `blast_radius` on flask `src/flask/cli.py` leaves out the example tests that build `Flask` through `create_app`.
- `blast_radius` at the default depth 2 stops one hop short of `Flask.__call__`.
- `codebase_outline` does not name test classes.

## Release checks

- `scripts/release-corpus-check.py` against v2.5.0 on 15 real projects plus the julie fixtures: PASS, with no changed tool output, symbols, or call edges.
- One dogfood round in Claude Code and Codex on a flask worktree used every tool and checked each answer against the source. It found no wrong answers. The gaps above come from that round.
- Linux, macOS, Windows, and plugin launcher test suites pass.

## Distribution

The GitHub release provides archives for six targets. Each archive bundles `code-kb` and the pinned `julie-extract` 3.7.2 with a `.sha256` checksum.
