# code-kb v2.2.2

This patch closes three of the four gaps that v2.2.1 listed, fixes the wrong answers that the 2.2.2 dogfood round found, and bundles julie-extract 3.6.3. The SQLite artifact schema stays at version 7.

## Fixed

- `find_references` for callers returned 0 for a constructor such as `Flask.__init__`, although flask builds `Flask()` in 19 places. The callers of a constructor now include the calls that build its class.
- `blast_radius` stopped at a constructor. On `src/flask/cli.py` it listed `Flask.__init__` and then nothing that builds an app. The walk now goes from a constructor to the calls that build its class, so the answer also lists the tests that build an app, because `Flask()` runs `cli.AppGroup()`. Rows reached only through a constructor come after the others, so the CLI tests stay first.
- `blast_radius` listed every function in a test file as a test to run, including app factories such as `create_app` in `tests/test_apps`. Such a symbol now counts as a test only when julie flags it as a test or fixture, it is a member of a test class, or its name reads like a test; otherwise it is an impacted symbol.
- `blast_radius` on `src/flask/cli.py` missed `test_cli_invoke` and the tutorial's `test_init_db_command`. A method call on a local variable now matches the class that the assigned call builds (`runner = app.test_cli_runner()`), by the class name or by the callee's return type. A pytest fixture follows the same rule, and a test sees only the fixtures of its own file and of a `conftest.py` in its folder or a folder above it.
- `find_references(direction="callees")` and `get_symbol_context` left out `self.should_ignore_error(error)`, a call to the class attribute `should_ignore_error: None = None`. A `self` call to a class attribute is now a callee.
- `find_structural_facts` showed `app.add_url_rule("/", endpoint="index")` as a second `GET /` route. A Flask route row now names its endpoint, and an `add_url_rule` row names its view or says `no view function`: `GET / (… endpoint: index, no view function, registered in: create_app)`.
- `lookup_symbol("Flask::handle_user_exception")` said that 0 rows had that exact name. A `::` qualified query now counts as exact.
- Doc lines in `lookup_symbol` and `search_symbols` stopped mid-sentence (`The actual WSGI application. This is not implemented in`). A doc line is now the first sentence of the first paragraph. Comment markers (`///`, `/**`, ` * `, `#`, `#'`, `<summary>`) no longer show in doc lines or in skeleton doc comments. Markdown sections keep their text as written.

## Faster

- The fixture rule in `find_references` and `blast_radius` read every fixture with the receiver's name in the project for each call site. On hermes-agent (988k symbols), `find_references` on a common method name took 30 s and `blast_radius` on one file took 20 s. They now take 18 s and 10.7 s. No measured call is slower than in v2.2.1.

## julie-extract 3.6.3

- JavaScript and TypeScript `x instanceof MyClass` is a type usage of `MyClass`.
- A TypeScript decorator keeps its arguments in the signature: `@Controller('users') class UsersController`.
- C++ anonymous unions are named `anonymous_union_603`, like anonymous structs.
- JavaScript constructor assignments `this.x = value` keep their rows beside a getter or setter named `x`, and TypeScript constructor assignments are property rows.
- A Flask route fact records its literal endpoint name.

The first call for each project rebuilds its index once, because the index was written by julie-extract 3.6.2. The old index stays in place until the new one is ready. Restart running MCP sessions after you update.

## Known gaps

- `blast_radius` `possible` tests are picked by shared words. For flask `handle_user_exception` they include some tests that never raise into it and miss tests such as `test_aborting`.
- A member-access row matches by name. `find_references(FlaskCliRunner.invoke)` keeps `runner.invoke` in a `tests/test_cli.py` fixture whose `runner` is click's `CliRunner`, which is not in the index.
- `search_symbols("WSGI request dispatch response error handling")` ranks `Flask.wsgi_app` 12th.
- `find_structural_facts` gives one row per method, can list `POST` before `GET` for one route, and points a decorator route at its `def` line.

## Release checks

- Dogfood sessions in Claude Code and Codex on a flask worktree used every tool and checked each answer against the source. The first round ran on the local julie build before its version bump and found four wrong answers. A second round on the published julie-extract 3.6.3 found two more in `blast_radius`. All six are fixed above with regression tests and a rerun of the failed call.
- `scripts/release-corpus-check.py` against v2.2.1 on 15 real projects plus the julie fixtures: PASS. Symbols, call edges, and scan times are unchanged except for julie-extract 3.6.3's 28 new TypeScript property rows in zod and one renamed C++ anonymous union. The changed tool outputs are the doc lines and the skeleton doc comments. The review of the first run found two defects in the new doc lines, fixed before release: a sentence ended at `(e.g.`, and comment markers showed.

## Distribution

The GitHub release provides archives for six targets. Each archive bundles `code-kb` and the pinned `julie-extract` 3.6.3 with a `.sha256` checksum.
