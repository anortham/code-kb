# code-kb v2.10.0

This release checks every language that julie-extract supports, keeps the
file watcher correct when folders are deleted and made again, and adds paging
to the reports. It bundles julie-extract 3.9.1 and keeps SQLite schema 8.

## Languages

- Every language that the pinned `julie-extract languages --json` reports is
  in scope. Real-extraction conformance tests cover all 42 languages.
  `docs/language-support.md` lists each capability, its tests, and the known
  gaps.
- A shared name does not tie two languages together. Impact, context, and
  callee answers keep calls in the same language, or in a language group that
  can call across (JavaScript and TypeScript, the JVM, .NET, C and C++, QML to
  C++).
- Related types and receiver fields bind through lexical scope, indexed
  imports, and exact owners. A shorter path or a matching field name no longer
  chooses a type.
- `get_symbol_context` binds related types through Python imports, Rust `use`
  paths, C and C++ includes, and C# and Razor usings and enclosing
  namespaces. It follows a file that imports the name again, such as a package
  `__init__.py` or a `pub use`. The parts of a C# partial class are one type.

## Callers report

- A receiver chain starts at a typed value, at the caller's class for `self`,
  `this`, or `cls`, or at a type that the caller's scope names. So
  `Outer.Inner.build()` in Python, Java, and C# is `proven` (`qualified path`)
  again, and `self.service.send()` is proven for the right service.
- A chain steps through a typed field, property, or constant
  (`Holder.INSTANCE`), a nested type, or an enum constant to its enum
  (`Color.RED`).
- A chain does not exclude a method in a companion object, an enum-constant
  body, a partial or reopened class, or an extension. Such a site stays
  `unresolved`.
- Argument counts apply in every language with a strict argument rule, not
  only seven. An Elixir pipe (`x |> f(a)`) counts the piped value, trailing
  Elixir `key: value` pairs count as one argument, and a Ruby block argument
  (`&blk`) and a `&block` parameter take no slot.
- The `Constructions` section covers Zig, F#, Elixir, and Ruby. A Zig return
  type and a Ruby `#` comment are no constructions.

## Paging

- `find_references`, `blast_radius`, and `check_edit` accept `offset` and
  `limit` (CLI `--offset` and `--limit`). Each section has its own page, and
  the counts describe the whole report. A page hint reads
  `[Showing N of T results; pass offset K to see more.]`.
- The first callers page uses the same window as later pages, so
  `offset` = `limit` continues every section and no row shows twice.
- MCP `offset` accepts a numeric string, as `limit` does.
- `blast_radius` can show the low-signal rows it found with
  `include_low_signal` (CLI `--include-low-signal`).
- CLI `refs --direction callees --json` leaves out calls into other
  languages, as the text and MCP answers do.

## Edit check

- The reads of a removed field are labeled by their receiver evidence, as
  `find_references` labels them. A read through a receiver whose type comes
  from an external module is no longer proven.
- A stale call with a required parameter that a receiver ties to the changed
  method stays `proven`, so the Stop hook blocks it.
- Required named parameters are checked in every language whose call reader
  can bind them.
- Removed members include the reads tied to their owner. A callback value is
  an advisory dependency when the callable changes.
- A broader test command needs a runner that the repository configures. A
  Gradle subproject runs through the nearest `gradlew` above it
  (`cd app && ../gradlew test`). The `npm init` placeholder script is no
  runner.

## File watcher

- A folder deleted and made again at the same path is watched again. Before,
  later edits in it were lost.
- After lost events (a queue overflow), every registered folder is watched
  again, because ext4 and XFS can give a new folder the old inode number.
- A subdirectory without read permission is skipped with a warning. Before,
  it made every MCP and CLI read fail. A project root without permission is
  still an error.
- Dropping a watcher does not wait for its worker, so a switch to another
  root does not block. A new watcher, an index rebuild, and a new index of the
  same root wait for the old worker.
- On Windows, one recursive watch covers the whole root. Before, each folder
  had its own handle and 16 KB buffer.
- Removing a folder no longer registers every other folder again.
- Reconcile never indexes the index file or its SQLite sidecars when `--db`
  puts the index inside the project. Before, every reconcile of such a root
  failed.
- The patched `notify-debouncer-full` is now a private module of
  `code-kb-core`, so the crates.io package has the fix too.

## Index rebuilds

- A rebuild, and a rescan of an index of another schema, scan into a side
  file and move it over the index. Before, the index was removed first, so a
  call during the scan was refused. A rebuild that writes no index keeps the
  old file.

## Outline

- `file_skeleton` on a folder leaves out the generated names of Python
  lambdas (`lambda_48`), so the real functions of the file show.

## Upgrade

- CLI `--json` keeps the whole report. `offset` and `limit` page only the
  text.
- Some sites change label: chains rooted at a type or at `self` become
  `proven` or `excluded`, and argument-count exclusions apply in more
  languages.
- Refresh a running MCP session after upgrading. No rescan is needed.

## Known gaps

- A TypeScript `Outer.Inner.build()` call is proven for every `Inner.build`,
  because julie writes only the last qualifier. This was so in 2.9.1.
- A Go composite-literal result call (`(&Handler{}).Handle()`) and Go
  block-local shadowing stay `unresolved`.
- An Elixir keyword pair with a quoted key counts as its own argument.
- The dogfood round on Flask found these gaps. Each answer is true but
  incomplete:
  - `check_edit` test lists for a removed field or a new required parameter
    can be too small when the symbol is used on every request. The list for
    a change to a tutorial function misses the tests that use the `app`
    fixture.
  - `blast_radius` on `src/flask/cli.py` misses tests that use the
    module-level `cli` and `run_command` objects or `FlaskGroup`.
  - `blast_radius` on `Flask.handle_user_exception` finds no test, because
    the tests reach it through werkzeug. It names the open end and says to
    run the full suite.
  - `get_symbol_context` on `Flask.__init__` lists 5 of about 100 tests that
    build `Flask`.
  - A call through a subscript (`environ[key](ctx)`) is no callee, because
    julie does not record it.
