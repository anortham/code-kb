# code-kb v2.3.0

This release bundles julie-extract 3.7.0, adapts reference resolution to it, and improves search for members of highly ranked types. The SQLite artifact schema stays at version 7.

## julie-extract 3.7.0

- julie no longer binds a call to a false target: a function that a local name shadows, a function in an unrelated scope, or a method whose name is only unique in the file. Those calls now stay pending for code-kb to resolve.
- Two calls to the same target on one line are two rows.
- Receivers come from the syntax tree (`a.b.run()` has receiver `b` and qualifier `a`).
- New structural facts: Actix `ServiceConfig` routes and scopes, local `reqwest` and Tesla clients, Rust benchmarks, Cucumber step methods in Java, Swift Testing traits, Kotest table and property checks, Phoenix sockets and channels, and regex conditionals and branch-reset groups.

The first call for each project rebuilds its index once, because the index was written by julie-extract 3.6.3. The old index stays in place until the new one is ready. Restart running MCP sessions after you update.

## Fixed

- julie-extract 3.7.0 refuses an incremental update of an index that another julie-extract build wrote. code-kb logged the refusal and answered from the old rows. It now rescans that index in place, so the answer is current.
- With julie-extract 3.7.0, `find_references` lost about half of the callers that julie stopped binding by name. code-kb now resolves them:
  - In Java, C#, Kotlin, Swift, C++, Scala, Dart, Ruby, and VB.NET, a call with no receiver reaches a method that the caller's class inherits (the nearest class that defines the name wins), and a method in another part of a C# `partial` class in the same file.
  - A call with no receiver reaches a definition in an enclosing function, namespace, or module, and a type nested in an enclosing class. The nearest scope that defines or imports the name wins.
  - A `this`, `self`, or `cls` call reaches a sibling member, such as another method of a JavaScript object literal.
- A base class that a pending `extends` row names counts only when no class of that name is closer to the subclass's file. Before, `Rack::Protection::AuthenticityToken < Base` also inherited from `Sinatra::Base`, so `blast_radius` on `Sinatra::Base.prototype` listed rack-protection methods.

## Search

- `search_symbols` also considers the direct members of the top-ranked code types, when a member's own name, signature, or doc matches a query word. The owner's name and doc give weak credit to query words that the member does not match.

## Known gaps

- These callers are still missed: a Ruby method called from a module that a class includes (`halt` in `Sinatra::Helpers`), a method of the base class of a Kotlin anonymous object, and C++ calls where julie records a wrong or missing parent symbol.
- `blast_radius` on a whole file is 10% to 40% slower on C# and Java projects, because the class-chain rules run for more calls. The slowest measured call went from 0.74 s to 1.2 s.
- `blast_radius` `possible` tests are picked by shared words. For flask `handle_user_exception` they include some tests that never raise into it and miss tests such as `test_aborting`.
- `blast_radius` on flask `src/flask/cli.py` lists 312 tests, because every test that builds `Flask` runs `cli.AppGroup()`.
- `search_symbols` labels a class-body assignment `variable` and a `self.` assignment `attribute`.

## Release checks

- One dogfood round in Claude Code and Codex on a flask worktree used every tool and checked each answer against the source. It found no wrong answers. The gaps it found are listed above.
- `scripts/release-corpus-check.py` against v2.2.2 on 15 real projects plus the julie fixtures: PASS. Symbols are unchanged. The lost call edges are calls that julie-extract 3.7.0 now leaves pending; a sample of 140 was checked through `find_references` by symbol ID. Most of the callers still missing were wrong targets in v2.2.2, such as `drop(x)` bound to `ChildGuard::drop`. Every new caller in samples from nine projects was checked against its source line.

## Distribution

The GitHub release provides archives for six targets. Each archive bundles `code-kb` and the pinned `julie-extract` 3.7.0 with a `.sha256` checksum.
