# code-kb v2.0.0

## Highlights

code-kb now exposes ten read-only MCP tools. Agents use their native filesystem tools for edits, while code-kb keeps the index current and supplies precise context, references, and test predictions.

## Breaking change: source editing tools removed

- `edit_file` and `replace_symbol_body` are no longer MCP tools. The `code-kb edit-file` and `code-kb edit` CLI commands are removed too.
- Replace those calls with the agent's native file editor or patch tool. Use `get_symbol_body` or `get_symbol_context` to inspect the target first; code-kb refreshes indexed files after filesystem changes.
- Agents discover the current tool list at session start. Refresh a running MCP session after upgrading so it sees the ten-tool schema.

## More precise read tools

- Lookup and search text now include each result's full current-index `symbol_id`. Body, context, references, and blast radius accept that ID through `symbol_id` or CLI `--symbol-id`, so same-name definitions can be selected exactly. An ID that disappears after a file refresh reports a reselection error; it never falls back to a name match.
- Blast radius distinguishes rows returned from rows discovered, reports output truncation and bounded-discovery ceilings, and handles an explicit `limit=0` without implying there are no callers or tests.
- Context test discovery now applies the same test-path policy as blast radius, including test files the extractor did not flag.
- MCP selector schemas remain compatible with Claude's tool API. Handlers enforce one nonempty name or ID and ignore JSON null placeholders.

## Compatibility and distribution

- The SQLite artifact schema is unchanged. The release bundles the pinned julie-extract 3.3.1 binary for all six supported targets.
- Symbol IDs identify definitions in the current index. Re-run lookup or search after edits or an index rebuild before reusing an ID. Unresolved call matching remains heuristic.
- The six platform archives and their `.sha256` sidecars are attached to the [v2.0.0 GitHub release](https://github.com/anortham/code-kb/releases/tag/v2.0.0).
