# code-kb v2.2.1

This patch fixes three defects that the v2.2.0 release check found in real projects. It also bundles julie-extract 3.6.1, which fixes Python instance attributes in `file_skeleton`. The SQLite artifact schema stays at version 7.

## Fixed

- `blast_radius` listed every file under a folder whose name contains the seed file's stem as a test to run. For flask `wsgi_app`, every file under `tests/test_apps/` was listed, including `.flaskenv`, CSS, and HTML files. A stem-matched test file must now match the stem in its own file name. A matched file also counts only when it holds a test or its name has `test` or `spec` as a whole word (`test_app.py`, `app_spec.rb`, `AppTest.java`), so fixture apps such as `tests/test_apps/cliapp/multiapp.py` and templates such as `test/fixtures/user.tmpl` are no longer listed.
- `lookup_symbol Flask` returned 17 import rows in 20. When an exact lookup finds a definition, the import rows with the same name now fold into one line with the count and the first three locations. `find_references` lists every use.
- `get_symbol_context` could list a test helper before a real test in the same test file, and the order could change between scans. The related tests now have a stable order: flagged tests first, then by path and line.
- Python (julie-extract 3.6.1): `self.x = v` in a method showed as the class attribute `x = v` in `file_skeleton`. The signature now keeps the receiver (`self.cli = cli.AppGroup()`).

## Upgrading

The first call for each project rebuilds its index once, because the index was written by julie-extract 3.6.0. The old index stays in place until the new one is ready. Restart running MCP sessions after you update.

## Release checks

- `scripts/release-corpus-check.py` against v2.2.0 on 15 real projects in 14 languages plus the julie fixtures: PASS. Symbols, call edges, typed receiver calls, and scan times are unchanged. Every changed tool output was reviewed: the Python skeleton and search signatures, the folded import lines, the shorter test lists in `blast_radius`, and the related-test order.
- The check also found two defects in the first 2.2.1 candidate, fixed before release. The import fold counted prefix matches (`lookup read` folded `readline` as an import of `read`). A file name that contained `spec` inside a word (`search-inspect.py`) counted as a test.

## Distribution

The GitHub release provides archives for six targets. Each archive bundles `code-kb` and the pinned `julie-extract` 3.6.1 with a `.sha256` checksum.
