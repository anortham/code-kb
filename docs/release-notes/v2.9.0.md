# code-kb v2.9.0

This release fixes the findings of the 2026-10-21 agent-utility review that
verification confirmed. Go receiver calls now reach their methods, a test mock
no longer hides real call sites, and `blast_radius` reports the callers it can
see. It bundles julie-extract 3.9.1 and keeps SQLite schema 8.

## Callers and blast radius

- Go methods link to their receiver types. julie leaves the parent of most Go
  methods empty, so callers, `blast_radius`, and `check_edit` did not follow a
  receiver call. In the reach gate, Go proven sites rose from 151 to 670 at
  precision 1.000. On cobra, `blast_radius execute` finds tests where it found
  none.
- A local object that a test builds (`var res = { send }`) ties receivers only
  inside its own function. Before, it excluded every real `res.send` call in
  express; now they are `likely`.
- `blast_radius` adds the direct callers that the callers report finds, with
  the reason `direct caller (find_references)`. When it cannot tie some sites,
  it says how many and points to `find_references`.
- A helper function nested in a test maps to that test.
- `blast_radius` with no target outside a git repository is an error, not
  "no uncommitted changes". CLI JSON adds `callers_report`.

## Lookup, skeletons, and search

- `lookup_symbol` shows `Did you mean` for a close name before the ranked
  rows. CLI JSON adds `suggestions`.
- `get_symbol_context` says when a name has more overloads than the four it
  shows.
- An empty `file_skeleton` says why: the top-level rows it hides, an
  unsupported file, or a file that is not indexed.
- Search drops rows that match only a digit-only word of the query, so a
  nonsense query returns nothing. Code rows rank before data, config, and
  document rows.

## Index and CLI

- An unreadable index is rebuilt. When the rebuild fails, the error names
  `code-kb scan --root <root>`.
- `code-kb check --fail-on-proven` exits 3, not 2, because clap uses 2 for
  usage errors. Update a script that tests for 2.

- A symlink such as `~/.code-kb/bin/code-kb` that points at a checkout build
  finds the checkout's `.tools/julie-extract`. Before, a harness that drops the
  environment (Codex) failed with `julie-extract not found`.

## Docs

- The README and site state measured savings, latency, and memory with their
  evidence. `AGENTS.md` and `CLAUDE.md` gain a Build and Test section.
- The release preflight reads file times portably.

## Upgrade

- Refresh a running MCP session after upgrading. The new Go links are written
  on the next start; no rescan is needed.
- `check --fail-on-proven` callers that expect exit 2 must expect 3.

## Known limits

- Go calls through a package-qualified receiver type (`cobra.Command`) or an
  interface are not followed.
- An empty `artifact.db`, or an index that goes corrupt during a session, is
  not rebuilt until the next start.
- A mock built by assignment inside a test function can still block the
  assigned-on-object rule.
- `refs --json` returns the full report regardless of `--limit`; the reach gate
  reads it.
- The dogfood round kept these gaps: `check_edit` does not report a removed
  class or instance attribute; `blast_radius` does not follow tests through the
  WSGI test client or functions used as values; qualified type annotations stay
  `unresolved`. [The dogfood report](../reviews/2026-10-22-v2.9.0-dogfood.md)
  lists every finding.
