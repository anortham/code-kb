# code-kb v2.0.1

This patch corrects misleading read-tool responses and improves targeted test suggestions. It keeps the ten-tool MCP catalog, SQLite artifact schema, and bundled julie-extract 3.3.1 unchanged.

## Fixes

- With `limit=0`, lookup, search, references, and structural facts now say that the limit hides results instead of claiming there are no matches. CLI JSON still returns the requested empty arrays.
- `blast_radius` now suggests tests named for a source module under `src/<module>/`. File-stem matches rank first; module discovery checks test basenames, skips generic module names, and has a bounded candidate scan.
- Blast-radius ceiling and empty-result text now covers both file-stem and module-name matching. MCP limit descriptions now state that facts and literals, and tests and impacted symbols, have separate result caps.
- The quality benchmark no longer targets a removed editing symbol and measures all ten MCP tools.

## Distribution

The GitHub release provides archives for six supported targets, each bundling `code-kb` with the pinned `julie-extract` binary and a `.sha256` checksum. Agents using a running MCP session should restart it after updating.
