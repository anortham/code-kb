# code-kb v2.0.2

This patch bundles julie-extract 3.5.0, up from 3.3.1. The SQLite artifact schema stays at version 7, and the ten MCP tools keep their names and parameters. Existing indexes rebuild on first use with the new extractor.

## Extraction updates

- The bundled extractor recognizes 42 languages and file formats. New `go.mod` and `go.sum` support exposes module dependencies and checksums through symbols and structural facts.
- The 3.4.0 language gap work adds file selection, embedded HTML and Vue extraction, and structural facts across the supported languages. The 3.5.0 release adds SpecFlow, Reqnroll, and Behat step-definition roles in symbol metadata.
- QML reference lookup now respects a local variable or parameter that shadows an `id` binding when resolving calls through that name. Handler calls use the handler symbol emitted by the new extractor.
- Source builds, agent guidance, the language page, and all six release-asset checksums now match the 3.5.0 pin.

## Performance

On the fixed code-kb snapshot, the six benchmark searches kept their top result. A 300-call MCP retest measured search p95 at 8.80 ms with 3.3.1 and 10.54 ms with 3.5.0. A larger upstream snapshot wrote 6.3% more symbols and took 14.95 to 17.86 seconds at the median for a fresh scan. See [the performance report](../reviews/2026-09-23-julie-3.5.0-performance.md) for workloads, raw evidence, and limits.

## Distribution

The GitHub release will provide archives for six supported targets, each bundling `code-kb` and the pinned extractor with a `.sha256` checksum. Restart a running MCP session after updating.
