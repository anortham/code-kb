# code-kb v2.11.2

This patch fixes `blast_radius` calls that took up to 6 minutes, and
`find_references` callee and `get_symbol_context` calls that took up to 44 s.
The answers do not change. It bundles julie-extract 3.10.0 and keeps SQLite
schema 8.

## Speed

A check of the tools on nine real projects found calls that took minutes.
The cause was one rule: the typed receiver-chain rule (`a.b.f()` through the
types of `a` and `b`). Each graph query placed the whole owner query of that
rule inside its match test, and SQLite ran it again for every call and
target pair it compared.

- The caller walk of `blast_radius`, the callees of `find_references`, and
  the callee signatures of `get_symbol_context` now find the owner of each
  call once, then compare against that list.
- A call with no owner skips the rest of the rule, because such a call can
  never prove a target.
- The check for a nearer top-level definition of the same name compares each
  other definition with one path test.

## Known gaps

The dogfood round on Flask found no wrong answer. It found these gaps. Each
answer is true but incomplete, and each was known in 2.11.1 unless noted.

- `blast_radius` and `get_symbol_context` list no test for
  `Flask.handle_user_exception`, which tests reach through the werkzeug test
  client. The answer names the open end.
- `blast_radius` labels `__init_subclass__`, which reads the target as a
  value, `direct caller (find_references)`.
- `blast_radius` on `src/flask/cli.py` leaves out `test_cli_name`, which reads
  the `cli` attribute that the `Flask` constructor sets, and shows one test
  file in several groups (new).
- `blast_radius` on a file counts test file groups as rows in `N returned`.
- `lookup_symbol` concept queries rank by shared words: "POST" also matches
  blog posts (new).
- `find_references Flask` labels `app: flask.Flask` annotations `likely`, and
  repeats construction sites in three sections.
- `check_edit` keeps 50 test commands in walk order, so the direct tests of a
  changed field can fall outside them.
- `get_symbol_body` calls a property getter and setter `overloads`.
- `get_symbol_context` lists no related test for `Flask.wsgi_app` (new).
- `file_skeleton` does not show the decorator of a view defined inside a
  function (new), and a folder skeleton counts an unsupported file without
  naming it (new).
- The callees of `Flask.wsgi_app` miss a call through a subscript
  (`environ["…"](ctx)`), which julie does not record (new).
