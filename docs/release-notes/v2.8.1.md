# code-kb v2.8.1

This patch corrects C# overload filtering, Java static-import verdicts, and
session attribution in hook telemetry. It bundles julie-extract 3.9.1, which
corrects C# argument types without changing SQLite schema 8.

## Caller and edit checks

- C# overload checks preserve custom namespaces. An argument typed `A.Token`
  cannot be treated as `B.Token`, and a project type named `String` cannot be
  treated as `System.String`.
- Argument-count checks omit a call only when exact type evidence binds it to
  another overload. A call that still fits the changed overload remains listed.
- Java static-import checks consider every explicit and wildcard import.
  Competing owners remain unresolved, regardless of import order.
- Julie reads C# local and parameter types only within their lexical scope,
  including blocks, loops, `catch`, `using`, and `fixed`. An unknown binding
  remains unknown instead of borrowing an outer type.
- C# integer argument types account for value, radix, and suffix.
  `typeof(...)` reports `System.Type`.
- Python annotation-only class declarations no longer prove a competing runtime
  value that excludes an assigned member's real uses.
- Adding a required Python keyword-only parameter keeps callers that do not
  supply it. An unknown `**kwargs` expansion remains unresolved.
- A TypeScript object shorthand that may write an interface member stays
  unresolved when the same token also reads a local value with that name.
- Test reports describe indexed evidence and label tests that call or use the
  symbol, including member reads.

## Hooks and replay

- Follow-through telemetry is scoped to the project, session, and diff.
  Separate sessions that block on the same diff no longer share an outcome.
  Existing rows without session identity remain unattributed.
- Replay resumes verify the executable's SHA-256, including rebuilds that keep
  the same version string. A changed executable or an unverified legacy run
  requires a new output directory; existing results remain readable by `score`.

## Upgrade

- Refresh a running MCP session after upgrading. code-kb rebuilds an index made
  by the previous extractor when it detects the new pin.
- SQLite schema remains 8. When using Julie directly, refresh a 3.9.0 schema 8
  artifact with `scan --force` before incremental use. For schema 7, extract
  into a new database path; `--force` does not migrate schema 7 in place.
- The review details and regression evidence are in
  [the release review](../reviews/2026-10-21-release-review.md).

## Known limits

The paired tool round found existing gaps in indirect runtime test reach,
file-level uses of functions as values, plain-class and instance-attribute
removal, and some returned-object callees. Display caps remain explicit.
[The dogfood report](../reviews/2026-10-21-v2.8.1-dogfood.md) records the
finite dispositions. The reach gate also retains two missing Zod edges;
no holdout cases or adjudications were changed.
