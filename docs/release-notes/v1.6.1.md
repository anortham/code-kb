# code-kb v1.6.1

## Highlights

This release bundles julie-extract 3.3.1 and strengthens Qt and QML support across QML, Qt JavaScript, and Qt C++ headers.

## Qt and QML

- Qt C++ `Q_PROPERTY` facts retain optional `DESIGNABLE`, `SCRIPTABLE`, `STORED`, `USER`, and `REVISION` metadata alongside type and accessor details.
- `facts pragma` now includes Qt JavaScript `.pragma` directives, with exact source spans for `.import` and `.pragma` symbols.
- QML object scopes, body spans, references, and single-turn edits cover nested objects and inline components more reliably.
- Header refreshes preserve Qt facts after edits and reconciliation. Changed header batches use one content-aware workspace scan, re-extracting only changed files.

## Performance and verification

- The corrected Qt header refresh path completed in 375 ms on the Plasma corpus, down from 15.4 s before the fix.
- The 215 saved search-quality cases kept their ranking results; search p95 improved from 342 ms to 333 ms.
- A focused lookup tail rose from 1.01 ms to 1.29 ms p95 while median latency remained effectively unchanged. See the [performance report](https://github.com/anortham/code-kb/blob/v1.6.1/docs/reviews/2026-09-22-julie-3.3.1-performance.md) for workload details.
- Verified with 416 Linux tests, 33 Windows tests, plugin launcher tests, formatting, and clippy.

## Compatibility

- Release archives bundle julie-extract 3.3.1. Existing indexes rebuild once when their extractor version differs.
- No MCP tool schema changed.

## Assets and checksums

The six platform archives and their `.sha256` sidecars are published with the [v1.6.1 GitHub release](https://github.com/anortham/code-kb/releases/tag/v1.6.1).
