# v2.12.0 release dogfood

Status: PASS; one wrong answer found and fixed before the tag.

## Round

One round, `20261031T210530Z`, ran one Claude Code session and one Codex session
on Flask at `d73fa1c`. Candidate commit: `8cfcf41`, built before the version
bump (it reports 2.11.2), with julie-extract 3.11.0. Each session used every
tool and checked its answers against the source. The lead checked each finding
against the source.

## Fixed

- `403704a`: with a path filter, a miss on a qualified name
  (`ScriptInfo.create_app` after its field was removed) said that the name "is
  defined in" unrelated module-level `create_app` functions. A qualified name now
  lists only definitions with that owner, and otherwise offers close names.
- `e371fdd` (found by the corpus check): a JavaScript `catch (error)` row cited
  a `const error` of a later block as its basis. A row on the bound name now
  cites its own binding line.

## Gaps

- `blast_radius` lists no test for a method that the runtime calls
  (`Flask.handle_user_exception` through the test client). The answer names the
  open ends and says to run the full suite.
- A `flask.Flask` type annotation is `likely`, while `flask.Flask(...)` calls are `proven`.
- `find_references` on `Flask` prints the text-only lines and repeats the constructions.
- `blast_radius` on `cli.py` misses `test_cli_name`; its default page hides the
  constructor fold, and its "returned" count counts groups and tests together.
- `check_edit` leaves out Python `obj.name = …` writes of a removed attribute,
  and a site that a property return type could prove stays `likely`.
- Concept lookup can fill its limit with rows that match no word.
- A folder outline does not name its unsupported files, and a skeleton does not
  show a function nested in a function.
- Callees leave out a call of a subscript result.

## Not defects

- `__init_subclass__` reads `cls.handle_user_exception` to inspect its
  signature. The read is a real reference, so the proven site is correct.
- `check_edit` reports `unresolved` sites as a count by design.
