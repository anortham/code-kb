## Gaps retained

- Dynamic test reach through the WSGI client is not followed. `handle_user_exception`
  can have no indexed test path even though runtime tests exercise it. The output
  recommends the full suite.
- File-level blast radius omits some imported functions used as values, including
  two `run_command` tests found by symbol-level queries. File mode skips that
  fallback. A complete bounded fix needs a batched resolver; running a report for
  each of `cli.py`'s 266 symbols would replace a 0.05-second query with up to 266
  report runs. No approximation was added.
- Plain-class attribute removal, removed instance attributes, and removed keyword
  arguments have incomplete edit coverage. Class fields are used for the
  documented construction checks; this release adds no new field-use analysis.
- Context tests and edit-check sites keep their explicit display caps. Full
  reference reports and CLI JSON provide more rows. Indirect tests remain incomplete.
- Qualified `flask.Flask` type hints can remain unresolved beside a test-local
  subclass. This is the existing v2.8.0 limit.
- Callees omit some calls through returned objects or subscript results. Search
  can rank name matches above an exact documentation phrase and does not search
  route decorators as a separate field.

## Correct or intentional output

Exact-name/body/skeleton results, import counts, the route facts, and the clean
post-restoration edit checks matched source. Lookup intentionally includes folded
prefix matches; a direct import lookup supplies the detailed import list. Class
reports include constructions, tests, and text-only counts. Generated lambda
names and hidden implementation details in skeletons are documented behavior.

The reported `response(...)` callee is unresolved because the response is a
local callable value; the external-callee option exposes it. The extra unrelated
`__init__` sites and conservative type-hint rows are unresolved, rather than
incorrectly proven or excluded.
