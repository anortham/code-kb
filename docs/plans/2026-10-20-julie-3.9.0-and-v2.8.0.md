## Task 2: julie, non-function JavaScript property values

`res.locals = res.locals || Object.create(null)` writes no symbol, so a read of `res.locals` is a `likely` site of a removed function `locals` (express dev case `4983c382`).
- [x] `extract_assignment` records `obj.prop = <value that is not a function>` as a `Property` symbol when `obj` is an identifier other than `this`, `module`, and `exports`: `className` is `obj`, the owner is the top-level function, class, or variable named `obj` when the file has one, and only the first such assignment of each `obj.prop` in a file counts.
- [x] julie tests for the symbol, the owner, and the one-per-file rule. A bare name as the value (`api.render = render`, `app.route = route`) writes no property (julie c81388f3, then 1f413aa6): such a row duplicated a function, or turned a parameter into a rival of every `route` method (express holdout case f41d09a3, 12 sites). The corpus check found two more wrong answers, fixed in julie before the tag: a chained assignment (`req.get = req.header = function header()`) wrote a property `get` that became the parent of the method `header`, and a property owned the calls in its value, so `opts.etag = this.app.enabled('etag')` made `etag`, not `sendFile`, the caller of `enabled`. Now a chained assignment writes no property, and no assigned property owns a reference.
- [x] code-kb: the express case shows no `res.locals` row; reach gate JavaScript and TypeScript tables hold. Result: 46 outside rows to 1 (`require('./utils').locals`, a true use).

## Task 3: julie, C# argument types

A C# call binds the overload its argument types select; the index records only `arg_count`, so a call of `Equals(JValue)` is listed for a change of `Equals(object)`.
- [x] Call identifiers get `arg_types`: one entry per argument, a type name or `null`. Known forms: a literal (`string`, `char`, `bool`, `int`, `long`, `double`, `float`, `decimal`), `new T(…)`, a cast `(T)e`, `e as T`, `typeof(…)` (`Type`), `nameof(…)` (`string`), `this` (the enclosing type), and a name bound to a typed local, parameter, or field.
- [x] code-kb: a C# call whose argument types are all known and equal to the parameter types of another overload of the same owner binds that overload: the check does not list it for a change of the first (`edit_check/binding.rs`). Deviation: the callers report is unchanged, because its target is the whole overload group, so a call of any overload is a true site of it.
