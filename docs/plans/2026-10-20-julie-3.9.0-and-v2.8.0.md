## Task 3: julie, C# argument types

A C# call binds the overload its argument types select; the index records only `arg_count`, so a call of `Equals(JValue)` is listed for a change of `Equals(object)`.
- [ ] Call identifiers get `arg_types`: one entry per argument, a type name or `null`. Known forms: a literal (`string`, `char`, `bool`, `int`, `long`, `double`, `float`, `decimal`), `new T(…)`, a cast `(T)e`, `e as T`, `typeof(…)` (`Type`), `nameof(…)` (`string`), `this` (the enclosing type), and a name bound to a typed local, parameter, or field.
- [ ] code-kb: a C# call whose argument types are all known and equal to the parameter types of another overload of the same owner binds that overload: the check does not list it for a change of the first, and the callers report excludes it with basis ``binds `Equals(JValue)` ``.
