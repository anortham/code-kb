The Prompt Context Problem

Stop Burning Context on Full Files

Traditional agents rely on full file reads and raw text grep. A 1,500-line source file consumes ~13,750 tokens. Over a typical 10-turn coding session, an agent burns 100,000+ tokens on irrelevant implementation details, inducing context compaction, forgotten constraints, hallucinated types, and astronomical API costs.

Anti-Pattern: Raw File Reflex ~13,750 tokens burned

Core Architecture

Engineered for Autonomous Coding Agents

Every design decision in code-kb solves a concrete defect experienced with earlier code intelligence systems.

🦴

Progressive Disclosure

codebase_outline for orientation, file_skeleton for interfaces with bodies stripped, and get_symbol_body for exact functions. O(signatures) token complexity rather than O(lines).

🔬

Surgical Context Slices

get_context_slice returns target implementation body + immediate callee signatures + parameter types + associated unit tests in one turn. Eliminates 4–6 follow-up search turns.

💥

Blast Radius & Test Prediction

Multi-hop reverse reachability via recursive SQLite CTEs. blast_radius auto-detects uncommitted git changes and predicts the minimal targeted test commands to run before/after edits.

⚡

Single-Turn Atomic Edits

replace_symbol_body performs pre-flight tree-sitter AST syntax validation, blake3 optimistic concurrency check, atomic file replacement, and SQLite re-indexing in a single turn. Zero two-step preview waste.

🪟

First-Class Windows & NTFS

Windows is never an afterthought. Releases ship Windows binaries verified in CI on native NTFS. Strip verbatim prefixes with dunce, forward-slash normalization, and rigorous file handle closure.

🪝

Cross-Platform Native Hooks

code-kb hook [SessionStart|SubagentStart] compiles routing guidance directly into the native binary. Outputs standard JSON in <1ms without Node.js, Python, or shell dependencies.

Understanding Latency: Engine vs. Model Reasoning
code-kb stats confirms that internal database queries take 0 to 5 milliseconds. Total agent turnaround time (e.g. 13s in Grok, 29s in Claude Code) is dominated by LLM chain-of-thought reasoning and network transmission. code-kb adds essentially zero overhead to agent turns while removing 90% of prompt tokens.
Progressive Workflow

From Exploration to Atomic Edit

A structured, token-dense lifecycle that guides agents without getting trapped in raw file grep loops.

Phase 1: Orientation

codebase_outline

Understand high-level architecture, module hierarchies, and primary exports in ~200 tokens.

codebase_outline(depth=2)
Phase 2: Interface Discovery

file_skeleton & search

Examine signatures and traits with bodies stripped. Use BM25 FTS5 for conceptual search.

file_skeleton("src/server.rs")
search_symbols("auth token validation")
Phase 3: Surgical Context

get_context_slice

Fetch target function body + callee signatures + parameter types + associated unit tests in one turn.

get_context_slice("handle_request")
Phase 4: Impact & Tests

blast_radius

Compute multi-hop reverse reachability via recursive CTEs and pinpoint minimal tests to run before/after editing.

blast_radius(symbol="compute_hash")
Phase 5: Atomic Edits

replace_symbol_body

Perform pre-flight tree-sitter AST validation, optimistic hash concurrency checks, and re-indexing in one turn.

replace_symbol_body(
  symbol="calculate",
  file="calc.rs",
  body="{ return a + b; }"
)
Phase 6: Verification

code-kb stats

Zero-overhead local telemetry in SQLite WAL mode. Track tool success rates, median latency, and token savings.

Tool Catalog

Complete MCP Tool Reference

Every MCP tool has an exact 1:1 CLI command for instantaneous terminal verification and agent dogfooding.

MCP Tool CLI Equivalent Description Zero-Friction Ergonomics
codebase_outline code-kb outline [path] Hierarchical directory tree & primary symbol outline Aliases: path, dir, depth
file_skeleton code-kb skeleton <file> File outline with implementation bodies stripped Aliases: file, path
find_symbol code-kb symbol <query> Exact and prefix symbol lookup with optional path filter Aliases: name, q, path
search_symbols code-kb search <query> Conceptual BM25 full-text search over docstrings & signatures Aliases: name, q, path
get_symbol_body code-kb body <symbol> Exact source code body for a single symbol Aliases: symbol, name, file
get_context_slice code-kb slice <symbol> Target body + callee signatures + parameter types + tests Aliases: symbol, name, file
find_references code-kb refs <symbol> Traverses callers or callees (filters external stdlib noise) Default direction: callers
blast_radius code-kb blast-radius [target] Multi-hop transitive impact & targeted test prediction Alias: impact; auto-detects git changes
find_structural_facts code-kb facts [category] Framework structural facts (routes, queries, models, configs) Omit category to list available categories
replace_symbol_body code-kb edit <symbol> Atomic AST-validated symbol replacement Aliases: body, code, expected_hash
Harness Integration

Quickstart & Agent Configuration

Configure code-kb in seconds across your favorite AI coding harness.

Claude Code (Anthropic CLI)

Option A: User-Level (Global across all projects — Recommended):

claude mcp add --scope user code-kb -- code-kb serve

Option B: Project-Level (Auto-discovered from .mcp.json):

{
  "mcpServers": {
    "code-kb": {
      "command": "code-kb",
      "args": ["serve"]
    }
  }
}

Grok CLI (xAI)

Option A: Plugin Install (Recommended — MCP + Skills + Lifecycle Hooks):

grok plugin install anortham/code-kb --trust
# or from local checkout:
grok plugin install /path/to/code-kb --trust

Option B: Project-Level (Automatically detected via .mcp.json):

{

      "command": "code-kb",
      "args": ["serve"]

  }
