The Prompt Context Problem

Traditional agents rely on full file reads and naive text grep. A 500-line source file consumes ~5,000 tokens. Over a 10-turn coding task, an agent consumes 50,000+ tokens on irrelevant implementation details, triggering context compaction, lost instructions, and high API costs.

Anti-Pattern

The Raw File Reflex

Agent runs grep, finds a match, then reads the entire 1,500-line file into its prompt window just to check a function's return type.

view_file("queries.rs")
# Tokens burned: ~13,750 tokens
# Result: Context window polluted
code-kb Solution

File Skeletons

Agent inspects types, structs, traits, and signatures with all implementation bodies stripped. Retains full architectural shape at a fraction of the cost.

file_skeleton("queries.rs")
# Tokens used: ~1,630 tokens
# Savings: 88.1% token reduction

Progressive Disclosure Workflow

A structured, token-dense lifecycle that guides agents from initial repo orientation to verified atomic edits.

Phase 1: Orientation

codebase_outline

Understand high-level architecture, module hierarchies, and primary exports in ~200 tokens.

codebase_outline(depth=2)
Phase 2: Interface Discovery

file_skeleton & search

Examine signatures and traits with bodies stripped. Use BM25 FTS5 for conceptual search.

file_skeleton("src/server.rs")
search_symbols("auth token validation")
Phase 3: Surgical Context

get_context_slice

In a single turn, fetch target function body + callee signatures + parameter types + associated unit tests.

get_context_slice("handle_request")
Phase 4: Impact & Tests

blast_radius

Compute multi-hop reverse reachability via recursive CTEs and pinpoint minimal tests to run before/after editing.

blast_radius(symbol="compute_hash")
Phase 5: Atomic Edits

replace_symbol_body

Perform pre-flight tree-sitter AST validation, optimistic hash concurrency checks, and re-indexing in one turn.

replace_symbol_body(
  symbol="calculate",
  file="calc.rs",
  body="{ return a + b; }"
)
Phase 6: Verification

code-kb stats

Zero-overhead local telemetry in SQLite WAL mode. Track tool success rates, median latency, and token savings.

Quickstart & Agent Configuration

Configure code-kb in seconds for Claude Code, Cursor, Antigravity, or Codex.

1. Claude Code (Anthropic CLI)

Add globally for all projects with a single command:

claude mcp add --scope user code-kb -- code-kb serve

2. Cursor IDE

Create .cursor/mcp.json in your project root:

{
  "mcpServers": {
    "code-kb": {
      "command": "code-kb",
      "args": ["serve", "--root", "${workspaceFolder}"]
    }
  }
}

3. Antigravity (AGY) & Standard MCP

Create .mcp.json in your project root:

{
  "mcpServers": {
    "code-kb": {
      "command": "code-kb",
      "args": ["serve"]
    }
  }
}
